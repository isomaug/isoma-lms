# Lesson 4: Multi-Character Stories - Two Characters, One Stage

**Duration:** 60 minutes (split across Week 4 Lesson 1 start + Lesson 2 finish)
**Term / Week:** Term 1 · Week 4
**Age Range:** 7–8 years
**Hardware:** Tablets / Shared Devices with Stack KIDI App
**Bloom's:** L3 Apply · L4 Analyse · L5 Evaluate · L6 Create

**Big Idea:** In Stack KIDI, each character has its OWN sequence of blocks - they run at the same time. Designing two characters to interact requires planning BOTH programmes before coding either.

**Source plan:** `Stage2_Lesson4_Week4.docx`

## Learning Objectives

- Add a second character to the Stack KIDI stage and give it a different name, colour, and starting position
- Write a separate 4-block sequence for each of the two characters
- Describe how both characters' programmes run at the same time when the Green Flag is pressed
- Evaluate whether the two characters' movements look like they are "interacting" and suggest one improvement

## Materials and Preparation

- 4 tablets with Stack KIDI (pairs' own projects from previous lessons)

## Cross-Curricular Links

**English:** Narrative with two characters: every story needs at least two characters to create INTERACTION. Learners write a one-sentence description of the relationship between their two characters: "Character 1 is ___ and Character 2 is ___. They meet when ___." Vocabulary: character, interact, stage, simultaneous, sequence, independent, programme.

**Maths:** Coordinates / positions: learners mark starting positions of both characters on the stage diagram using a simple 3×3 grid (left/centre/right × top/middle/bottom). This introduces the concept that each character has an independent position (x,y). Count: "How many blocks does Character 1 have? Character 2? Total = ___."

## Lesson Structure

### HOOK - The Two-Character Drama (8 min)
1. Two-Character Story Planner (A4 per pair) - split-page: left = Character 1 programme plan, right = Character 2 programme plan, with a stage diagram in the centre to show starting positions
2. Character design mini-cards (blank A6 cards) - each pair designs both characters with name, colour, and role in the story
3. Block sequence planning strips (blank horizontal strips, 4 squares each) - pairs draw block icons for each character before coding
4. Interaction evaluation card (A5) - "Does it look like they interact? YES / PARTLY / NOT YET. What would make it better?"
5. Projector/TV for facilitator to model the two-character setup
6. Two facilitators (or two learner volunteers) stand at opposite sides of the room.
7. Facilitator 1 calls out: "I am going to walk forward, stop, then bow." Does it. Facilitator 2 calls out: "At the SAME TIME - I am going to run to the centre, spin, then wave."

### DESIGN - Plan Both Characters (15 min)
8. Both perform simultaneously. Ask the class: "Did they interact? Did they bump into each other? Did their movements feel connected?"
9. Bridge: "Stack KIDI works the same way. Each character runs its own programme at the same time. Our job today is to make two programmes that feel like a STORY - not just two random movements."
10. Show a finished 2-character Stack KIDI project on the projector. Ask: "What does Character 1 do? What does Character 2 do? Do they look like they are in the same story?"
11. Distribute Two-Character Story Planners and character design mini-cards.
12. Step 1 (3 min): Each pair decides on a story (e.g. a cat chases a mouse; a robot delivers a gift to a friend; a child and their dog play in a park).
13. Step 2 (4 min): Design both characters on the mini-cards - name, colour, role. Agree: which is Character 1, which is Character 2?
14. Step 3 (4 min): On the stage diagram in the centre of the planner, mark where each character starts using initials (C1 and C2) on the 3×3 grid. They should NOT start at the same position.

### DELIVER - Code Both Characters (27 min)
15. Step 4 (4 min): On the block planning strips, draw 4 block icons for each character.
16. At least one block must be different between the two characters.
17. Facilitator approves the plan before the pair proceeds to coding.
18. Open Stack KIDI. Open or create the pair's existing project.
19. Step 1 - Add Character 2 (5 min): Tap the "+" button in the character panel. Choose a new character from the library OR use the paint editor to draw a custom character.
20. Rename it (Character 2's name). Move it to the planned starting position by dragging on the stage.
21. Step 2 - Code Character 1 (8 min): Select Character 1 in the character panel (tap it).

### DISCOVER - Interaction Evaluation (7 min)
22. Build the 4-block sequence from the planning strip. Run - observe only Character 1 moves.
23. Step 3 - Code Character 2 (8 min): Select Character 2. Build its own 4-block sequence from its planning strip. Run - only Character 2 moves (Character 1 stays still when Character 2 is selected).
24. Step 4 - Run both together (6 min): Click on the STAGE background (not a character) then press the Green Flag. BOTH characters run their programmes simultaneously. Observe: does it look like a story? Does it match the plan?
25. Distribute Interaction Evaluation Cards.
26. Each pair evaluates their OWN programme: "Does it look like the two characters are in the same story? YES / PARTLY / NOT YET."
27. Pairs then swap tablets with the adjacent pair. Evaluate the OTHER pair's programme: same question.

### WRAP-UP (3 min)
28. Return tablets. Compare own evaluation to partner pair's evaluation. Discuss: "Did you agree? What did the other pair notice that you missed?"
29. Each pair makes ONE improvement based on the evaluation and re-runs. Document the improvement on the evaluation card.
30. Save all projects. Learners give their project a title that describes the story (tap the project name field).
31. Quick show-and-tell: each pair says their story title and one sentence about what happens.
32. Collect evaluation cards for facilitator portfolio records.
33. Preview: "Next term we will add SOUND to each character and use LOOPS to make the interaction repeat - our stories will come alive!"

## Assessment

- Formative (During)
- Two-Character Story Planner completed: both characters designed, positions marked, 4-block sequences planned (facilitator approval before coding)
- Two characters on stage with different names, colours, and starting positions (screen observation)
- Both programmes run simultaneously when Green Flag pressed (demonstration to facilitator)
- Interaction Evaluation Card completed for own and partner programme
- Exit Assessment
- "Explain to me why each character needs its OWN set of blocks." Target: learner explains that characters run simultaneously and independently. Facilitator records: full explanation / partial / not yet.
- Differentiation
- Support: Facilitator adds Character 2 to the stage for the learner; learner focuses on building the 4-block sequence for Character 2 only (Character 1's sequence is pre-built).
- Extension: Add a third character (an audience member or narrator figure) with a minimal 2-block animation (e.g. waving) and write a 3-character story title. Then try to make one character APPEAR to respond to another by timing their movements (offset start positions and number of steps to appear to "meet" at the centre).
