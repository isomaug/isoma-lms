# Week 5 - Lesson 2

## Session length
**About half of this week's plan** (finish what you started in Lesson 1)

## Finish the week
- Distinguish between a finite loop (Repeat N) and an infinite loop (Repeat Forever) with a real-world example for each
- Implement a Forever loop in Stack KIDI and observe that it runs until the Red Stop button is pressed
- Add a Stop block at the end of a finite sequence to demonstrate intentional programme termination
- Design a programme that uses a finite loop for one part and a different trigger for a second independent character

## Continue

### DELIVER - Build Both Loop Types (30 min)
1. Build a SECOND programme (for Character 2, or a second row):
2. Green Flag -> Spin -> [no Repeat End - just keep adding Spin blocks? No] - use the Forever/Endless loop structure.
3. In Stack KIDI this is achieved by omitting the Repeat End and instead connecting back - or using a very large repeat number (99).
4. Discuss with class: "What happens? Does it ever stop?"
5. Press Red Stop to end Programme B.
6. Record time it ran.

### DISCOVER - Stop Condition Debate (10 min)
7. Compare: did Programme A stop by itself? Did Programme B need manual stopping?
8. Programme C - Design Challenge (10 min): Each pair implements their design challenge card brief. Check your work carefully - checks:
9. ① Which loop type used?
10. ② Is the Stop condition intentional?
11. ③ Does the programme match the brief?
12. You poses: "A traffic light programme should loop forever. Do you agree?" You discuss for 90 seconds.

### WRAP-UP (4 min)
13. Share: you give their verdict + reason. Decide. "Yes - forever" vs "No - finite."
14. Key insight: "For a traffic light running at a real junction - yes, forever. For a traffic light in a 10-second animation - finite. The CONTEXT decides the loop type."
15. You update their loop comparison table with one new example in each column based on today's builds.
16. You writes: "I used a ___ loop because ___ in today's programme."
17. Save all projects. Collect tablets.
18. Preview: "Next lesson - we discover how to send MESSAGES between characters to make them communicate!"

## Check your understanding
- Formative (During)
- Loop comparison table completed with examples for both loop types
- Programme A (finite) - stops after exactly 4 iterations with Stop block
- Programme B (large repeat / forever) - runs until manual stop, time recorded
- Design challenge card programme implemented with correct loop type and justification
- Exit / Summative
- "When would you use a Forever loop? When would you use Repeat N?" Learner must give one example for each. Target: real-world example that is different from the ones given in the lesson.
- Differentiation
- Support: You pre-builds Programme A up to the Repeat End block; learner adds the Stop block and sets the number. Extension: Build a programme for TWO characters - Character 1 uses Repeat N (5 times), Character 2 uses Forever. Run them simultaneously and observe which stops first. Write an explanation of what happened.
