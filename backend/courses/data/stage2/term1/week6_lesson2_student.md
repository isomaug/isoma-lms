# Week 6 - Lesson 2

## Session length
**About half of this week's plan** (finish what you started in Lesson 1)

## Finish the week
- Explain what a message is in Stack KIDI - a signal sent from one character to trigger another character's programme
- Set up a Send Message block at the end of Character 1's sequence and a matching Receive Message block at the start of Character 2's sequence
- Demonstrate that Character 2 does NOT start until Character 1 has sent the message
- Design a 2-character "call and response" interaction where the characters appear to have a conversation through movement

## Continue

### DELIVER - Build the Message System (28 min)
1. After the last movement block, add a SEND MESSAGE block.
2. Tap the colour inside - select the pair's chosen colour token colour.
3. The message is now queued at the end of Character 1's sequence.
4. Step 3 - Add Receive Message to Character 2 (8 min): Select Character 2.
5. REMOVE the Green Flag trigger from Character 2's sequence.
6. Replace it with a RECEIVE MESSAGE trigger.

### DISCOVER - Script the Conversation (10 min)
7. Set it to the same colour as the send block. Now Character 2 starts ONLY when the message arrives.
8. Step 4 - Run and compare (7 min): Press Green Flag.
9. Only Character 1 runs. Wait.
10. When Character 1 finishes and sends the message - Character 2 begins.
11. Fill in the right side of the comparison worksheet.
12. Each pair writes a 2-line "script" for what their characters are "saying" through their movements.

### WRAP-UP (4 min)
13. Share: each pair performs a live reading of their script while the programme runs in the background. Does the timing match?
14. Discussion: "Could you use messages to make a 3-character chain? Character 1 -> message -> Character 2 -> message -> Character 3?" One pair attempts a 3-step chain (you assists).
15. Class reflection: "What is the most important word in messaging?" (Timing / Coordination - accept both.)
16. Save projects. Collect comparison worksheets for portfolios.
17. You answers: "The difference between Green Flag start and Receive Message start is ___."
18. Preview: "Next lesson - we put everything together to build our Term 1 project - a full interactive story with all the skills we've learned."

## Check your understanding
- Formative (During)
- Call-and-response design strip completed (approved before coding)
- Comparison worksheet both sides completed (before and after message)
- Character 2 demonstrably waits for Character 1's message before starting (you observation)
- "Script" written for 2-character conversation
- Exit / Summative
- "Why did we change Character 2's trigger from Green Flag to Receive Message?" Learner must mention: timing / dependency / Character 2 should only start after Character 1 finishes. Full answer = all three concepts; partial = one concept.
- Differentiation
- Support: You sets the Send Message colour on Character 1; learner only needs to set the matching Receive colour on Character 2. Extension: Build a 3-character chain reaction - Character 1 sends to Character 2, Character 2 sends to Character 3. Time the total story from start to Character 3 finishing.

## Stay safe
Safeguarding Note: "Messaging" in Stack KIDI is entirely local and internal - reassure you that no messages leave the device and nothing is sent to the internet.
