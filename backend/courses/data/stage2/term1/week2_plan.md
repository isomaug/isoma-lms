# Lesson 2: Repeat Blocks - Teaching Computers to Loop

**Duration:** 60 minutes (split across Week 2 Lesson 1 start + Lesson 2 finish)
**Term / Week:** Term 1 · Week 2
**Age Range:** 7–8 years
**Hardware:** Tablets / Shared Devices with Stack KIDI App
**Bloom's:** L2 Understand · L3 Apply · L4 Analyse

**Big Idea:** A loop makes a computer repeat the same action many times without writing the same instruction again and again. Loops make programmes shorter and smarter.

**Source plan:** `Stage2_Lesson2_Week2.docx`

## Learning Objectives

- Explain what a loop does using an everyday life example (heartbeat, clapping rhythm, seasons)
- Convert a 6-block repetitive sequence into a 2-block loop + repeat number in Stack KIDI
- Determine the correct number to put in the Repeat End block to achieve a desired outcome
- Compare a "without loop" programme to a "with loop" programme and state which is more efficient and why

## Materials and Preparation

- 4 tablets with Stack KIDI (pairs' existing projects from Stage 2 Lesson 1)
- Loop comparison worksheet (A4 per pair) - two side-by-side programme diagrams: no loop vs. with loop
- Block reference poster showing the yellow Repeat End block (the orange repeat-loop bracket)

## Cross-Curricular Links

**English:** Vocabulary of repetition: "again and again", "over and over", "repeatedly", "again". Learners write 2 sentences: one describing their loop programme using these words.

**Maths:** Multiplication connection: 3 repeats × 2 blocks = 6 blocks total. Repeated addition: 2 + 2 + 2 = 6. Learners fill in: "My loop repeats ___ times. That is like ___ + ___ + ___ = ___."

## Lesson Structure

### HOOK - Loop Alive! (10 min)
1. "Loop in Real Life" picture cards - 8 pictures: clapping hands, spinning fan, wheels turning, heartbeat line, sun rising and setting, traffic lights, school bell, washing machine
2. Counting beads or tally chart strip per pair for recording loop iterations
3. Whole class stands. Facilitator says: "Clap 4 times. Now clap 4 times again. Now clap 4 times again." (Learners clap 12 times total.)
4. Ask: "Was that well organized? Could I say it in fewer words?" Introduce: "Clap 4 times, REPEAT that 3 times." Try it.
5. Show Loop in Real Life picture cards. Each pair receives 2 cards. Ask: "Is this a loop? How many times does it repeat?" Pairs discuss.
6. Bridge: "A LOOP in Stack KIDI works exactly like a clapping rhythm - it does the same thing over and over a set number of times."
7. Distribute comparison worksheets.

### DESIGN - No Loop vs. Loop Worksheet (10 min)
8. Left side shows: Move Forward × Move Forward × Move Forward × Move Forward × Move Forward × Move Forward (6 blocks).
9. Right side shows: [Repeat bracket → Move Forward → Repeat End (number = ?)] = 3 blocks total.
10. Task: "Fill in the ? on the right side. How many times must it repeat to do the same as the left?"
11. Pairs discuss. Answer: 6 repeats. Ask: "How many fewer blocks did we need? 6 − 3 = 3 blocks saved."
12. Introduce the maths link: "6 forwards = 1 forward × 6 times. That is multiplication!"

### DELIVER - Build With and Without a Loop (28 min)
15. Move Forward 6 times in a row (no loop - literally drag 6 Move Forward blocks).
16. Run and observe. Count the blocks.
17. Pair records on worksheet: "Number of blocks without loop: ___"
18. Part B - With Loop (10 min):
19. Now build the SAME movement using the Repeat structure.
20. In Stack KIDI, use the Repeat End (curved orange block) to wrap the sequence.

### DISCOVER - Efficiency Debate (8 min)
21. Set the number to 6.
22. Run.
23. Pair records: "Number of blocks with loop: ___". Calculate: "Blocks saved: ___"
24. Part C - Experiment (8 min): Change the repeat number. Try 3. Try 10. Record what happens each time in the tally chart. Which number makes the character return closest to its starting point?
25. Pairs join to form groups of 4. Share comparison worksheets.
26. Discussion prompt: "A programme has 20 of the same block in a row. Would you use a loop? Why?"

### WRAP-UP - Exit Reflection (4 min)
27. Each group prepares one sentence: "A loop is better than repeating blocks because ___."
28. Groups share. Facilitator writes key reasons on the board. Class votes for the clearest explanation.
29. Real-world link: "When an app on your phone plays a song on repeat - that is a loop! When a loading spinner spins - that is a loop!"
30. Each learner fills in the exit card: "A loop makes the computer ___ the same instruction ___ times. Without a loop I needed ___ blocks. With a loop I only needed ___ blocks."
31. Save Stack KIDI projects. Return tablets to charging station.
32. Facilitator previews: "Next lesson - we give our characters CHOICES using IF blocks!"

## Assessment

- Formative (During)
- Comparison worksheet: correct number filled in (6 repeats = 6 forward movements)
- Both programmes built and run (with and without loop) - facilitator observation checklist
- Tally chart of 3 different repeat numbers tested
- Efficiency statement written: "A loop is better because ___"
- Exit Assessment
- Exit card completed with all 4 blanks filled correctly. Facilitator target: every learner can state at minimum "A loop repeats the same instruction [n] times."
- Differentiation
- Support: Facilitator builds the "without loop" version together with the learner; learner builds the "with loop" version independently.
- Extension: Build a loop that includes TWO different blocks inside the loop (e.g. Move Forward + Jump), run, and predict total number of moves and jumps.
