# Week 8 - Lesson 1

## Session length
**About half of this week's plan** (you will finish in Lesson 2)

## Today you will learn
- Deliver a 90-second structured presentation to a guest audience, explaining algorithm, loop, and message used
- Demonstrate the project running live and narrate each character's programme as it runs
- Use at least 5 computing vocabulary terms correctly during the presentation
- Complete a peer evaluation form for one other pair's project, providing evidence-based feedback

## Big idea
Explaining your code to someone who has never seen it before is one of the best ways to understand it yourself. The best programmers can explain their work clearly, simply, and with pride.

## What you need
- 4 tablets with Stack KIDI — you' Lesson 7 projects fully loaded and tested

## Links to English and Maths
- **English:** Public speaking: 90-second structure, subject vocabulary, narrating a live demonstration. You rehearse twice before guests arrive. Evaluative language on peer form: "I could see… because…", "This showed… skill because…", "One suggestion: ___." Vocabulary used in certificates: accomplished, demonstrated, achieved.
- **Maths:** Quantitative reporting: "My project has ___ blocks. I used ___ types of block. My self-assessment score was ___ / 8 (___ %). The loop in my project repeats ___ times making ___ total actions." You report at least two numbers during their presentation.

## Let's begin

### PREPARATION — Rehearsal and Station Setup (15 min)
1. Presentation structure cards (A5 for you): 90-second structure: ① Story title + characters (15s) ② Press Green Flag — narrate Page 1 (30s) ③ Explain algorithm + loop used (20s) ④ Show message coordination (15s) ⑤ "I am proudest of ___" (10s)
2. Demo Day rubric (A4 for you, scored by you) — 5 criteria: Vocabulary / Algorithm explained / Loop demonstrated / Message demonstrated / Confidence and Clarity (each 0–3)
3. Peer Evaluation Form (A5) — "The project I evaluated was ___. One thing that worked really well: ___. The computing skill I could see most clearly: ___. One suggestion: ___."
4. Stage 2 Computing Passport (A5 booklet, 1 for you) — skills for Term 1: Algorithm / Bug / Loop / Multi-character / Messages / Project Brief
5. Term 1 Certificate (pre-printed, A5, 1 for you)
6. Final project check: run Lesson 7 project. Any single critical bug — fix now (5 minutes max). If project is broken, fall back to Lesson 6 multi-character project.

### DELIVER — Demo Day Presentations (28 min)
7. Get ready to use presentation structure cards. Each pair reads through the 5 steps and fills in your own content (title, character names, loop details, message colour).
8. Rehearsal round 1: present to own partner only — 90 seconds timed. Partner checks: ① Did you use 5 vocab words? ② Did you explain the loop? ③ Did you show the message?
9. Rehearsal round 2: present to the adjacent pair — full audience experience. Adjacent pair gives one piece of feedback from the peer evaluation form.
10. Set up stations: tablet + project brief + storyboard + presentation structure card visible on desk.
11. Welcome guests. You explains the programme in 2 minutes: "These you have spent Term 1 learning to think like programmers — designing algorithms, fixing bugs, and building interactive stories."
12. Rotation begins: guests visit stations in groups of 2. Each pair presents their 90-second showcase to every visiting group.
