# Week 7 - Lesson 2

## Session length
**About half of this week's plan** (finish what you started in Lesson 1)

## Finish the week
- Plan a complete 2-page, 2-character interactive story using a project brief template before writing any code
- Apply at least four different types of block from Term 1: movement, sound, loop, message, trigger
- Use the 3-step debugging process independently to identify and fix at least one bug encountered during the build
- Evaluate the completed project against a 4-criterion success checklist and give it a self-assessed score

## Continue

### DISCOVER - Self-Evaluation (6 min)
1. Build in order: ① Set Page 1 background. ② Add and name Character 1. ③ Build Character 1's sequence (include a loop). ④ Add Send Message at end of Character 1. ⑤ Add and name Character 2 on Page 1. ⑥ Build Character 2's sequence with Receive Message trigger. ⑦ Add Page 2. ⑧ Set Page 2 background. ⑨ Build a short arrival sequence on Page 2.
2. You checkpoint at 15 minutes: "Has every pair got at least Page 1 built and running?" You not at this point receive you assistance.
3. Bug encountered? Use 3-step process: Identify (what is wrong?) -> Locate (which block?) -> Fix (change one thing at a time). Record any bugs fixed on the back of the project brief.
4. Stick block type stickers onto the brief as each block type is successfully used.
5. Timer alarm at 35 minutes: coding stops regardless of completion. You run the current state and note what is complete and what is missing.
6. Get ready to use Self-Assessment Scoring Cards. Each pair scores their project on all 4 criteria.

### WRAP-UP (4 min)
7. Calculate total: ___ / 8. Calculate percentage.
8. Write: "I am most proud of ___ because ___. If I had more time, I would add ___."
9. Pair presents score and "most proud of" statement to the adjacent pair. Adjacent pair gives one "One Star, One Wish."
10. Save projects. Collect project briefs and scoring cards for portfolio folders.
11. Write down scores for you - these feed into the Term 1 Demo Day rubric.
12. Preview: "Next lesson - DEMO DAY! We present to guests. Practise your explanation tonight using the sentence starters on your project brief."

## Check your understanding
- Formative (During)
- Project brief approved before any coding begins (you sign-off)
- You checkpoint at 15 min build mark: Page 1 running
- Block type sticker sheet: minimum 4 sticker types applied
- Bug recorded and fixed on back of brief (debugging process used)
- Self-assessment score: target 6/8 minimum for Demo Day readiness
- Exit / Summative
- Self-assessment scoring card completed. You reviews: is the self-assessment accurate? If a learner scored 8/8 but the project is incomplete, have a 1-minute conversation about honest self-evaluation.
- Differentiation
- Support: Simplify brief - only 1 page, 1 character, 3 block types. You assists with message setup. Extension: Add a third page showing an "ending" scene, and add a third character who only appears on Page 3 as a reward for completing the journey.
