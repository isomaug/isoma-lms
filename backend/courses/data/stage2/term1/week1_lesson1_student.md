# Week 1 - Lesson 1

## Session length
**About half of this week's plan** (you will finish in Lesson 2)

## Today you will learn
- Define an algorithm as "a set of precise, step-by-step instructions to solve a problem or tell a story"
- Create a 5-step story map algorithm using pictures and arrows showing a character's journey
- Identify at least one error in a given "buggy" algorithm and suggest a correction
- Implement the first 3 steps of the story map as Stack KIDI blocks and run the programme

## Big idea
An algorithm is a plan. Good programmers plan on paper before they code. A story map IS an algorithm.

## What you need
- 4 tablets with Stack KIDI (new projects)
- Algorithm Story Map template (A4 for you) - 5 numbered panels with arrows between them
- Block reference poster (movement, trigger, end blocks)
- Printed "Buggy Algorithm" cards - 3 scenarios with deliberate ordering errors
- Coloured pens for story map drawing
- Class wall chart: "Algorithm = A plan with steps in the right order"

## Links to English and Maths
- **English:** Narrative structure: Beginning -> Middle -> End maps onto Algorithm Step 1 -> Steps 2–4 -> Step 5. You write the story map captions using a new verb in each panel (hop, spin, zoom, hide, wave). Vocabulary: algorithm, precise, instruction, sequence, plan.
- **Maths:** Ordinal numbers: 1st step, 2nd step, 3rd step… Counting steps in an algorithm. Comparison: "My algorithm has 5 steps. My partner's has 4. How many more do I have?"

## Let's begin

### HOOK - The Recipe Game (8 min)
1. Read a deliberately muddled recipe: "Put the bread on the plate. Spread the butter. Cut the bread. Get the bread from the bag." Ask: "What is wrong with this recipe?"
2. You suggest the correct order. Write steps on the board 1–4 in the right order.
3. Introduce the word ALGORITHM: "A recipe is an algorithm for cooking. Today we write an algorithm for a character in Stack KIDI."
4. Show the wall chart. You read aloud: "Algorithm = A plan with steps in the right order."
5. Get ready to use Story Map templates. Explain the 5 panels.

### DESIGN - Create Your Story Map Algorithm (18 min)
6. Task: "Plan a journey for your character. It starts at HOME, goes somewhere, does something, comes back."
7. Each panel must have: a drawing of what happens AND a direction word (forward/backward/turn/jump/spin).
8. Check your story map carefully. Partner checks: "Does Step 2 come BEFORE Step 3? Does the order make sense?" Then suggest one improvement.
9. Look at an example 5-step story map on the projected screen: a character walking to school, turning left, finding a ball, spinning, returning home.
10. Introduce "Bug Hunt": you show a buggy algorithm on projected screen (Step 4 and Step 5 swapped). Ask: "What is wrong? How do we fix it?"

### BUG HUNT - Find the Errors (7 min)
11. Get ready to use Buggy Algorithm cards (3 different scenarios).
12. Identify the error on your card and write/draw the correction.
13. Share: present one scenario. Decide: "Is your fix correct?"
14. Key teaching: "A bug is a mistake in an algorithm. Fixing bugs is called DEBUGGING."
15. Open Stack KIDI, new project. Name the character using your own name or initials.

## Save your progress
Keep your Stack KIDI project, story map, and notes ready for Lesson 2, where you will finish this week's activities and check your learning.
