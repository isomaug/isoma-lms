# Lesson 5

**Duration:** 60 minutes (split across Week 5 Lesson 1 start + Lesson 2 finish)
**Term / Week:** Term 1 · Week 5
**Age Range:** 7–8 years
**Hardware:** Tablets with Stack KIDI App
**Bloom's:** L2 Understand · L3 Apply · L4 Analyse

**Big Idea:** Some loops stop after a set number of repeats. Others loop forever - until someone stops them. Knowing WHEN to stop is as important as knowing how to loop.

**Source plan:** `Stage2_Lesson5_Week5.docx`

## Learning Objectives

- Distinguish between a finite loop (Repeat N) and an infinite loop (Repeat Forever) with a real-world example for each
- Implement a Forever loop in Stack KIDI and observe that it runs until the Red Stop button is pressed
- Add a Stop block at the end of a finite sequence to demonstrate intentional programme termination
- Design a programme that uses a finite loop for one part and a different trigger for a second independent character

## Materials and Preparation

- 4 tablets with Stack KIDI - pairs' projects from Lesson 4
- Loop type comparison table (A4 per pair) - two columns: "Repeat N: stops after ___ times" vs "Repeat Forever: stops when ___"
- Timer (phone or watch) - facilitator times how long a Forever loop runs before learners press stop
- Red Stop card (laminated A5 per pair) - to hold up as a metaphor before pressing the actual stop button

## Cross-Curricular Links

**English:** Words that describe "ongoing" vs "ending": while, until, forever, eventually, finally, always. Learners write: "The Forever loop runs ___ until ___." And: "The Repeat 5 loop runs ___ times and then ___." Vocabulary: finite, infinite, terminate, condition, intentional.

**Maths:** Finite vs infinite sets: 1, 2, 3, 4, 5 (finite - it ends) vs 1, 2, 3, 4, 5… (infinite - it continues). Learners draw a number line with an arrow pointing right to represent "forever." Contrast with a closed-ended number line. Link: infinite loop = number line with no end; finite loop = number line with a marked endpoint.

## Lesson Structure

### HOOK - The Forever Machine (8 min)
1. Design challenge cards (4 different cards) - each card gives a brief for a programme that must use a Forever loop and a Stop condition
2. Stop signal poster on wall: "A programme without a Stop can run forever. Always plan WHERE it ends."
3. Facilitator points to a fan or ceiling fan image: "Does a fan have a built-in stop? No - it runs until YOU switch it off. That is a Forever loop."
4. Then points to a microwave timer: "Does a microwave have a built-in stop? Yes - it stops when the timer reaches zero. That is a Repeat N loop."
5. Learners call out 5 more examples - does it run forever or stop by itself? Class votes. Tally on board.
6. Show the Stop Signal poster. "Every programme needs a plan for stopping - even if the stop is a human pressing a button."
7. Distribute loop comparison tables.

### DESIGN - Loop Comparison Table (8 min)
8. Left column (Repeat N): learners fill in: "Stops after ___ times. Good for: ___. Example: ___."
9. Right column (Repeat Forever): "Stops when ___. Good for: ___. Example: ___."
10. Pairs share their "Good for" examples with the class. Facilitator picks 2 best examples per column.
11. Introduce design challenge cards. Each pair reads their card brief. They must identify: "Should this use Repeat N or Repeat Forever? Why?"
12. Programme A - Finite Loop (10 min): Open Stack KIDI. Build:
13. Green Flag → Move Forward → Turn Right → Repeat End (4).
14. This creates a partial square.

### DELIVER - Build Both Loop Types (30 min)
15. Add a Stop block (red) after the Repeat End.
16. Run and confirm it stops after 4 iterations.
17. Programme B - Forever Loop (10 min):
18. Build a SECOND programme (for Character 2, or a second row):
19. Green Flag → Spin → [no Repeat End - just keep adding Spin blocks? No] - use the Forever/Endless loop structure.
20. In Stack KIDI this is achieved by omitting the Repeat End and instead connecting back - or using a very large repeat number (99).
21. Discuss with class: "What happens? Does it ever stop?"

### DISCOVER - Stop Condition Debate (10 min)
22. Press Red Stop to end Programme B.
23. Record time it ran.
24. Compare: did Programme A stop by itself? Did Programme B need manual stopping?
25. Programme C - Design Challenge (10 min): Each pair implements their design challenge card brief. Facilitator circulates - checks:
26. ① Which loop type used?
27. ② Is the Stop condition intentional?
28. ③ Does the programme match the brief?

### WRAP-UP (4 min)
29. Facilitator poses: "A traffic light programme should loop forever. Do you agree?" Pairs discuss for 90 seconds.
30. Share: pairs give their verdict + reason. Class votes. "Yes - forever" vs "No - finite."
31. Key insight: "For a traffic light running at a real junction - yes, forever. For a traffic light in a 10-second animation - finite. The CONTEXT decides the loop type."
32. Pairs update their loop comparison table with one new example in each column based on today's builds.
33. Each learner writes: "I used a ___ loop because ___ in today's programme."
34. Save all projects. Collect tablets.
35. Preview: "Next lesson - we discover how to send MESSAGES between characters to make them communicate!"

## Assessment

- Formative (During)
- Loop comparison table completed with examples for both loop types
- Programme A (finite) - stops after exactly 4 iterations with Stop block
- Programme B (large repeat / forever) - runs until manual stop, time recorded
- Design challenge card programme implemented with correct loop type and justification
- Exit / Summative
- "When would you use a Forever loop? When would you use Repeat N?" Learner must give one example for each. Target: real-world example that is different from the ones given in the lesson.
- Differentiation
- Support: Facilitator pre-builds Programme A up to the Repeat End block; learner adds the Stop block and sets the number. Extension: Build a programme for TWO characters - Character 1 uses Repeat N (5 times), Character 2 uses Forever. Run them simultaneously and observe which stops first. Write an explanation of what happened.
