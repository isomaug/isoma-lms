# Week 1 - Lesson 2

## Session length
**About half of this week's plan** (finish what you started in Lesson 1)

## Finish the week
- Define an algorithm as "a set of precise, step-by-step instructions to solve a problem or tell a story"
- Create a 5-step story map algorithm using pictures and arrows showing a character's journey
- Identify at least one error in a given "buggy" algorithm and suggest a correction
- Implement the first 3 steps of the story map as Stack KIDI blocks and run the programme

## Continue

### DELIVER - Code the First 3 Steps (20 min)
1. Task: implement ONLY Steps 1, 2, and 3 from your story map as Stack KIDI blocks.
2. Step 1 -> first block;
3. Step 2 -> second block;
4. Step 3 -> third block. Must start with the Green Flag trigger block.
5. Run the programme. Does it match the story map? If not - is it a bug in the code OR a bug in the story map? Fix whichever needs fixing.

### DISCOVER - Algorithm Exhibition (5 min)
6. Check your work carefully with observation checklist:
7. ① Green Flag trigger present
8. ② 3 blocks in sequence
9. ③ Sequence matches story map steps 1–3.
10. Each pair places story map on desk next to tablet.

### WRAP-UP (2 min)
11. You walk around and look at 2 other you' work. They must find: one similarity and one difference from your own algorithm.
12. Think: "What did algorithms have in common?" Write down responses on board.
13. Exit reflection: you completes the sentence: "An algorithm is ___."
14. Save projects. Collect tablets and story map sheets (kept in learner folders).
15. Preview: "Next lesson - we use LOOPS to make our character repeat actions!"

## Check your understanding
- Formative (During)
- Story map algorithm completed (5 panels with drawings + direction words)
- Bug Hunt card - error identified and corrected correctly
- Stack KIDI: 3-block sequence matching story map Steps 1–3 (you checklist)
- Exit Assessment
- Learner writes on an exit slip: "An algorithm is ___." Check for: key words (steps, order, instructions, plan).
- Differentiation
- Support: Provide a partially completed story map with Steps 1 and 5 pre-filled; learner completes Steps 2–4. Extension: Complete all 5 steps in Stack KIDI and add a sound block at Step 3.
