# Week 2 - Lesson 2

## Session length
**About half of this week's plan** (finish what you started in Lesson 1)

## Finish the week
- Explain what a loop does using an everyday life example (heartbeat, clapping rhythm, seasons)
- Convert a 6-block repetitive sequence into a 2-block loop + repeat number in Stack KIDI
- Determine the correct number to put in the Repeat End block to achieve a desired outcome
- Compare a "without loop" programme to a "with loop" programme and state which is more efficient and why

## Continue

### DELIVER - Build With and Without a Loop (28 min)
1. Pair records on worksheet: "Number of blocks without loop: ___"
2. Part B - With Loop (10 min):
3. Now build the SAME movement using the Repeat structure.
4. In Stack KIDI, use the Repeat End (curved orange block) to wrap the sequence.
5. Set the number to 6.
6. Run.

### DISCOVER - Efficiency Debate (8 min)
7. Pair records: "Number of blocks with loop: ___". Calculate: "Blocks saved: ___"
8. Part C - Experiment (8 min): Change the repeat number. Try 3. Try 10. Record what happens each time in the tally chart. Which number makes the character return closest to its starting point?
9. You join to form groups of 4. Share comparison worksheets.
10. Discussion prompt: "A programme has 20 of the same block in a row. Would you use a loop? Why?"
11. Each group prepares one sentence: "A loop is better than repeating blocks because ___."

### WRAP-UP - Exit Reflection (4 min)
12. Groups share. You writes key reasons on the board. Decide for the clearest explanation.
13. Real-world link: "When an app on your phone plays a song on repeat - that is a loop! When a loading spinner spins - that is a loop!"
14. You fills in the exit card: "A loop makes the computer ___ the same instruction ___ times. Without a loop I needed ___ blocks. With a loop I only needed ___ blocks."
15. Save Stack KIDI projects. Return tablets to charging station.
16. You previews: "Next lesson - we give our characters CHOICES using IF blocks!"

## Check your understanding
- Formative (During)
- Comparison worksheet: correct number filled in (6 repeats = 6 forward movements)
- Both programmes built and run (with and without loop) - you observation checklist
- Tally chart of 3 different repeat numbers tested
- Efficiency statement written: "A loop is better because ___"
- Exit Assessment
- Exit card completed with all 4 blanks filled correctly. You target: every learner can state at minimum "A loop repeats the same instruction [n] times."
- Differentiation
- Support: You builds the "without loop" version together with the learner; learner builds the "with loop" version independently.
- Extension: Build a loop that includes TWO different blocks inside the loop (e.g. Move Forward + Jump), run, and predict total number of moves and jumps.

## Stay safe
Safeguarding Note:  Ensure you do not set repeat numbers above 20 - very high numbers can freeze the app. You to demonstrate the max recommended value.
