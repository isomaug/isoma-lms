# Week 5 - Lesson 1

## Session length
**About half of this week's plan** (you will finish in Lesson 2)

## Today you will learn
- Distinguish between a finite loop (Repeat N) and an infinite loop (Repeat Forever) with a real-world example for each
- Implement a Forever loop in Stack KIDI and observe that it runs until the Red Stop button is pressed
- Add a Stop block at the end of a finite sequence to demonstrate intentional programme termination
- Design a programme that uses a finite loop for one part and a different trigger for a second independent character

## Big idea
Some loops stop after a set number of repeats. Others loop forever - until someone stops them. Knowing WHEN to stop is as important as knowing how to loop.

## What you need
- 4 tablets with Stack KIDI - you' projects from Lesson 4
- Loop type comparison table (A4 for you) - two columns: "Repeat N: stops after ___ times" vs "Repeat Forever: stops when ___"
- Timer (phone or watch) - you times how long a Forever loop runs before you press stop
- Red Stop card (laminated A5 for you) - to hold up as a metaphor before pressing the actual stop button

## Links to English and Maths
- **English:** Words that describe "ongoing" vs "ending": while, until, forever, eventually, finally, always. You write: "The Forever loop runs ___ until ___." And: "The Repeat 5 loop runs ___ times and then ___." Vocabulary: finite, infinite, terminate, condition, intentional.
- **Maths:** Finite vs infinite sets: 1, 2, 3, 4, 5 (finite - it ends) vs 1, 2, 3, 4, 5… (infinite - it continues). You draw a number line with an arrow pointing right to represent "forever." Contrast with a closed-ended number line. Link: infinite loop = number line with no end; finite loop = number line with a marked endpoint.

## Let's begin

### HOOK - The Forever Machine (8 min)
1. Design challenge cards (4 different cards) - each card gives a brief for a programme that must use a Forever loop and a Stop condition
2. Stop signal poster on wall: "A programme without a Stop can run forever. Always plan WHERE it ends."
3. You points to a fan or ceiling fan image: "Does a fan have a built-in stop? No - it runs until YOU switch it off. That is a Forever loop."
4. Then points to a microwave timer: "Does a microwave have a built-in stop? Yes - it stops when the timer reaches zero. That is a Repeat N loop."
5. You call out 5 more examples - does it run forever or stop by itself? Decide. Tally on board.
6. Show the Stop Signal poster. "Every programme needs a plan for stopping - even if the stop is a human pressing a button."
7. Get ready to use loop comparison tables.
8. Left column (Repeat N): you fill in: "Stops after ___ times. Good for: ___. Example: ___."
9. Right column (Repeat Forever): "Stops when ___. Good for: ___. Example: ___."

### DESIGN - Loop Comparison Table (8 min)
10. You share their "Good for" examples with yourself. You picks 2 best examples per column.
11. Introduce design challenge cards. Each pair reads your card brief. They must identify: "Should this use Repeat N or Repeat Forever? Why?"

13. Green Flag -> Move Forward -> Turn Right -> Repeat End (4).
14. This creates a partial square.
15. Add a Stop block (red) after the Repeat End.
16. Run and confirm it stops after 4 iterations.
