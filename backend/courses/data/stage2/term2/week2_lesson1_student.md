# Week 2 - Lesson 1

## Session length
**About half of this week's plan** (you will finish in Lesson 2)

## Today you will learn
- Locate the Wait block in Stack KIDI and explain its purpose: to pause the current character's programme for a set number of seconds
- Build a sequence where a Wait block creates a meaningful dramatic pause before an action
- Coordinate two characters performing one after the other using ONLY Wait blocks (no message blocks)
- Compare Wait-block coordination with Message-block coordination and explain one advantage of each

## Big idea
A pause is not empty time — it is the moment before something happens. In theatre, actors use pauses for effect. In code, a Wait block is the pause that makes the next action more powerful.

## What you need
- 4 tablets with Stack KIDI — existing multi-character projects from Term 1

## Links to English and Maths
- **English:** Time connectives in narration: "First Character 1 moves. MEANWHILE, Character 2 waits. THEN, after 2 seconds, Character 2 responds." You write a 3-sentence narration for their choreographed performance using three different time connectives. Vocabulary: pause, interval, meanwhile, simultaneously, elapse, choreograph, coordinate.
- **Maths:** Time calculation: Wait block values are in tenths of a second. Wait 10 = 1 second. Wait 25 = 2.5 seconds. You complete: "My Character 2 waits ___ units before starting. That equals ___ seconds. Character 1's programme takes ___ seconds. So the total performance lasts ___ seconds."

## Let's begin

### HOOK — The Orchestra Conductor (8 min)
1. Wait block reference card (A5 for you): clock icon, units = tenths of a second, examples: Wait 5 = half a second, Wait 10 = 1 full second, Wait 20 = 2 seconds
2. Choreography design sheet (A4 for you): two columns — Character 1 programme with wait values written in; Character 2 programme with wait values. A timeline at the bottom showing when each character is active
3. Stopwatch (phone timer) for you — for measuring how long sequences take with and without waits
4. Comparison table (A4): three columns — Method / Advantage / Disadvantage — two rows: Wait blocks / Message blocks
5. You stands at the front as a "conductor." Points to three learner groups — each group has a different action (clap, stamp, hum). Conductor cues each group at different times using a baton gesture.
6. Ask: "Could the orchestra play itself without a conductor — just using precise timing?" Try: give each group a wait time (Group 1 starts immediately, Group 2 waits 3 seconds, Group 3 waits 6 seconds). Try it with a countdown timer.

### DESIGN — Choreography Design Sheet (10 min)
7. Bridge: "A Wait block IS the conductor's pause. It tells a character: do nothing for ___ seconds, then start."
8. Show the Wait block reference card. Explain the units: Wait 10 = 1 second. "Who can figure out: what is Wait 15?" (1.5 seconds.)
9. Get ready to use choreography design sheets.
10. Each pair plans a 2-character performance. Character 1 starts immediately. Character 2 must wait until Character 1 reaches a specific moment.
11. In the timeline at the bottom, mark when Character 1 starts and ends, and when Character 2 starts (which must be DURING or AFTER Character 1).
12. Calculate: how many Wait units does Character 2 need? (Count Character 1's estimated running time in seconds × 10 units per second.)
