# Lesson 10  ·  Term 2 · Week 2

**Duration:** 60 minutes (split across Week 2 Lesson 1 start + Lesson 2 finish)
**Term / Week:** Term 2 · Week 2
**Age Range:** 7–8 years
**Hardware:** Tablets with Stack KIDI App
**Bloom's:** L2 Understand · L3 Apply · L4 Analyse

**Big Idea:** A pause is not empty time — it is the moment before something happens. In theatre, actors use pauses for effect. In code, a Wait block is the pause that makes the next action more powerful.

**Source plan:** `Stage2_Lesson10_Term2_Week2.docx`

## Learning Objectives

- Locate the Wait block in Stack KIDI and explain its purpose: to pause the current character's programme for a set number of seconds
- Build a sequence where a Wait block creates a meaningful dramatic pause before an action
- Coordinate two characters performing one after the other using ONLY Wait blocks (no message blocks)
- Compare Wait-block coordination with Message-block coordination and explain one advantage of each

## Materials and Preparation

- 4 tablets with Stack KIDI — existing multi-character projects from Term 1

## Cross-Curricular Links

**English:** Time connectives in narration: "First Character 1 moves. MEANWHILE, Character 2 waits. THEN, after 2 seconds, Character 2 responds." Learners write a 3-sentence narration for their choreographed performance using three different time connectives. Vocabulary: pause, interval, meanwhile, simultaneously, elapse, choreograph, coordinate.

**Maths:** Time calculation: Wait block values are in tenths of a second. Wait 10 = 1 second. Wait 25 = 2.5 seconds. Learners complete: "My Character 2 waits ___ units before starting. That equals ___ seconds. Character 1's programme takes ___ seconds. So the total performance lasts ___ seconds."

## Lesson Structure

### HOOK — The Orchestra Conductor (8 min)
1. Wait block reference card (A5 per pair): clock icon, units = tenths of a second, examples: Wait 5 = half a second, Wait 10 = 1 full second, Wait 20 = 2 seconds
2. Choreography design sheet (A4 per pair): two columns — Character 1 programme with wait values written in; Character 2 programme with wait values. A timeline at the bottom showing when each character is active
3. Stopwatch (phone timer) per pair — for measuring how long sequences take with and without waits
4. Comparison table (A4): three columns — Method / Advantage / Disadvantage — two rows: Wait blocks / Message blocks
5. Facilitator stands at the front as a "conductor." Points to three learner groups — each group has a different action (clap, stamp, hum). Conductor cues each group at different times using a baton gesture.

### DESIGN — Choreography Design Sheet (10 min)
6. Ask: "Could the orchestra play itself without a conductor — just using precise timing?" Try: give each group a wait time (Group 1 starts immediately, Group 2 waits 3 seconds, Group 3 waits 6 seconds). Try it with a countdown timer.
7. Bridge: "A Wait block IS the conductor's pause. It tells a character: do nothing for ___ seconds, then start."
8. Show the Wait block reference card. Explain the units: Wait 10 = 1 second. "Who can figure out: what is Wait 15?" (1.5 seconds.)
9. Distribute choreography design sheets.
10. Each pair plans a 2-character performance. Character 1 starts immediately. Character 2 must wait until Character 1 reaches a specific moment.

### DELIVER — Build Timed Choreography (28 min)
11. In the timeline at the bottom, mark when Character 1 starts and ends, and when Character 2 starts (which must be DURING or AFTER Character 1).
12. Calculate: how many Wait units does Character 2 need? (Count Character 1's estimated running time in seconds × 10 units per second.)
13. Facilitator approves: "Is the Wait value specific? Is there a timeline showing both characters?" Tick and proceed.
14. Open the existing 2-character Stack KIDI project from Term 1.
15. Step 1 — Measure Character 1 (5 min): Run Character 1's programme with a stopwatch. Record exact running time in seconds. Convert to Wait units (× 10). Note on design sheet.

### DISCOVER — Choreography Performance (10 min)
16. Step 2 — Add Wait to Character 2 (8 min): At the START of Character 2's programme row, add a Green Flag trigger (if not already present), followed immediately by a Wait block set to the calculated value. Run both characters simultaneously — does Character 2 start at the right moment?
17. Step 3 — Fine-tune timing (8 min): Adjust the Wait value until the transition looks natural. Try Wait value −2, exact value, and +2. Record which looks best and why.
18. Step 4 — Compare methods (7 min): Open the comparison table. Recall the Message block approach from Term 1. Fill in: "Wait blocks — Advantage: ___. Disadvantage: ___. Message blocks — Advantage: ___. Disadvantage: ___."
19. Each pair performs their choreographed 2-character story to the adjacent pair.
20. Audience watches and answers: "Did the timing feel natural? When did Character 2 start — too early, just right, or too late?"

### WRAP-UP (4 min)
21. Performers adjust based on feedback if needed (one change only, 2 minutes maximum).
22. Class discussion: "When is it better to use Wait blocks instead of Message blocks?" (Answer: when you know exactly how long something takes. Message blocks are better when you don't know — or when timing might vary.)
23. Each learner completes: "Wait blocks are useful when ___. Message blocks are better when ___."
24. Save choreography projects. Collect design sheets.
25. Preview: "Next lesson — we combine Wait blocks, Size, Speed, and Variables to build the most complex programme so far this term!"

## Assessment

- Formative (During)
- Choreography design sheet approved: timeline drawn, Wait value calculated
- Wait block value measured, calculated, and adjusted (3 values tested)
- Comparison table completed (Wait vs Message advantages and disadvantages)
- Audience timing feedback received and adjustment made (if needed)
- Exit / Summative
- "What is the difference between a Wait block and a Message block?" Learner must reference: timing certainty — Wait requires you to know how long; Message fires automatically when the condition is met. Both concepts correct = full mark.
- Differentiation
- Support: Facilitator pre-calculates the Wait value; learner only needs to find the Wait block and set the number. Extension: Build a 3-character choreography where Character 3 waits for BOTH Character 1 AND Character 2 to finish before starting — calculate the total wait time for Character 3.

## Safeguarding

Safeguarding Note: Timing discussions: avoid references to waiting in contexts that could be anxiety-inducing (e.g. waiting for test results, medical waits). Keep all Wait block examples in a positive, creative, story-based context.
