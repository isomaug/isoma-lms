# Week 5 - Lesson 2

## Session length
**About half of this week's plan** (finish what you started in Lesson 1)

## Finish the week
- Explain the connection between IF-THEN conditional logic in Stack KIDI and the basis of machine learning: "a computer that responds differently based on input"
- Design an "adaptive response" feature for the collaborative project: a programme section that produces one of two or three different outputs based on the current score variable or tap count
- Implement the adaptive response as a conditional sequence — if score < 3 -> one response; if score ≥ 3 -> a different response
- Evaluate whether the adaptive response makes the programme feel more "intelligent" and explain why to a non-specialist in one sentence

## Continue

### DELIVER — Implement the Adaptive Response (28 min)
1. You approves: "Is the threshold specific? Are the two responses clearly different? Does this make the programme seem to KNOW something about the player's performance?"
2. Open the collaborative integrated project from Lesson 19.
3. Step 1 — Conditional logic trace (5 min): Complete the trace worksheet with the planned threshold value. "If score = 1 -> which branch? If score = 3 -> which branch? If score = 5 -> which branch?" Confirm understanding before coding.
4. Step 2 — Build Branch 1 (10 min): After the main game mechanic, add the conditional check: IF score < threshold -> play Branch 1 response. Test with a score below threshold. Does Branch 1 fire? Record in trace worksheet.
5. Step 3 — Build Branch 2 (8 min): Add ELSE (or second trigger): IF score ≥ threshold -> play Branch 2 response. Test with a score at and above threshold. Does Branch 2 fire correctly?

### DISCOVER — The Intelligence Discussion (8 min)
6. Step 4 — Full game run with adaptive response (5 min): Play the game from start to finish twice — once reaching the low-score response, once reaching the high-score response. Confirm both branches work. Record on the Adaptive Response Design Sheet: "Branch 1 tested: YES/NO. Branch 2 tested: YES/NO."
7. Groups run both branches for the adjacent group. Adjacent group answers: "Does this programme seem to KNOW something about the player?"
8. Think about: "We just made our programme seem intelligent. It responds differently based on performance. Is it actually intelligent? What is missing for it to be truly AI?"
9. Key insight: "It is intelligent in a LIMITED way. It knows exactly two things: score < 3 or score ≥ 3. Real AI learns new thresholds from data instead of having one fixed number. But the principle is identical."
