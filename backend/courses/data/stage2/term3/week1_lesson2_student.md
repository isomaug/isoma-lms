# Week 1 - Lesson 2

## Session length
**About half of this week's plan** (finish what you started in Lesson 1)

## Finish the week
- Work in a group of 4 to produce a collaborative project brief with clearly assigned responsibilities for each pair
- Design two sub-systems (one for you) that are independently buildable AND can be integrated
- Define the interface between the two sub-systems: what message, page, or shared variable connects them
- Document the collaboration process: who decided what, how disagreements were resolved, and what the final agreement is

## Continue

### DISCOVER - Interface Test (6 min)
1. INDIVIDUAL PAIR DESIGN (15 min): Each pair works independently on their Sub-system Design Strip. They plan their programme in full - blocks, states, sounds, triggers - as if it were a solo project. The other pair does the same simultaneously.
2. INTERFACE DEFINITION (8 min): Groups reconvene. Each pair explains their sub-system to the other pair. Together, complete the Interface Design Card: "When Sub-system A ends, it sends ___ message. Sub-system B receives this and ___."
3. INTEGRATION CRITERIA (5 min): Write 4 integrated success criteria - 2 that can be tested on Sub-system A alone, 2 that require BOTH sub-systems to work together.
4. NEGOTIATION RECORD (4 min): Complete 3 rows of the Negotiation Record honestly. Check: "Did every person in the group contribute to at least one decision?"
5. Each group presents their Interface Design Card to yourself in 45 seconds: "Sub-system A does ___. Sub-system B does ___. They connect via ___."
6. Class checks: "Is the interface specific enough? Could these be built separately and still connect? Is there any ambiguity?"

### WRAP-UP (4 min)
7. Groups update their Interface Design Card based on any clarification questions raised.
8. You approves the Collaborative Project Brief with initials. No approval = must be revised overnight.
9. File Collaborative Project Briefs safely - returned at the start of Lesson 18.

## Check your understanding
- Formative (During)
- Collaborative Project Brief: all sections completed and approved
- Interface Design Card: interface defined specifically enough to build to (you check)
- Negotiation Record: 3 decisions documented, all group members contributed
- Individual Sub-system Design Strips: both completed independently and reviewed together
- Exit / Summative
- "What is the interface between your sub-system and your partner pair's? Describe it in one sentence using the words 'sends' and 'triggers'." Learner must name the message or trigger that connects the two sub-systems.
- Differentiation
- Support: Reduce the interface to the simplest possible form - Sub-system A on Page 1, Sub-system B on Page 2. The "interface" is simply a page transition. No complex message needed. Extension: Design a third integration point - a SHARED VARIABLE that both sub-systems can read and update. Plan how this shared variable (e.g. a score) changes in both sub-systems and how it is displayed.

## Stay safe
Safeguarding Note: Group formation: ensure groups are formed thoughtfully. Pair children with different strengths rather than same-ability pairing. Monitor any group dynamics where one learner dominates the design process and intervene to ensure all voices are heard.
