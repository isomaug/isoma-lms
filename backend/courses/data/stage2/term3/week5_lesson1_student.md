# Week 5 - Lesson 1

## Session length
**About half of this week's plan** (you will finish in Lesson 2)

## Today you will learn
- Explain the connection between IF-THEN conditional logic in Stack KIDI and the basis of machine learning: "a computer that responds differently based on input"
- Design an "adaptive response" feature for the collaborative project: a programme section that produces one of two or three different outputs based on the current score variable or tap count
- Implement the adaptive response as a conditional sequence — if score < 3 -> one response; if score ≥ 3 -> a different response
- Evaluate whether the adaptive response makes the programme feel more "intelligent" and explain why to a non-specialist in one sentence

## Big idea
AI is not magic — it is a very large, very fast collection of IF-THEN rules. The same logic you used to make a character respond to a tap is the same logic — at enormous scale — that drives voice assistants, recommendation engines, and medical diagnosis tools.

## What you need
- 2 tablets per group — integrated collaborative project from Lesson 19

## Links to English and Maths
- **English:** Explaining a technical concept to a non-specialist: you must practise the sentence "AI is ___ because ___" until it is both accurate and accessible. The target audience for this explanation is "a grandparent who has never used a smartphone." This requires stripping out jargon and using analogies. Vocabulary: artificial intelligence, conditional, response, input, adaptive, pattern, scale, decision, intelligent, analogy.
- **Maths:** Branching logic as a number line: "Score < 3" means the score is in the set {0, 1, 2}. "Score ≥ 3" means {3, 4, 5, …}. You complete: "If the game has a maximum score of 5, how many values are in the first branch? ___ How many in the second? ___" Introduction to set theory and inequality notation.

## Let's begin

### HOOK — What IS Artificial Intelligence? (10 min)
1. AI Awareness Introduction Card (A5 for you): a simple explanation of AI as conditional logic at scale — 5 sentences with a concrete everyday example from Uganda (mobile money fraud detection, M-Pesa security alerts)
2. Adaptive Response Design Sheet (A4 per group): "When score < ___ -> character does ___. When score ≥ ___ -> character does ___." (two-branch conditional design). Plus: "What does this make the programme seem to KNOW?"
3. Conditional logic trace worksheet (A5): a 5-step sequence with an IF-THEN branch. You trace through with 3 different input values and record what happens in each case
4. Real-world AI connection cards (4 cards): M-Pesa fraud alert, Makerere AI crop disease detector, phone face unlock, Spotify song recommendation — each described as "IF-THEN at scale"
5. You: "Has anyone used M-Pesa? Has it ever sent you an alert saying 'unusual activity detected'?" Hands up.
6. "How did the phone KNOW it was unusual? It was NOT a human checking every transaction. It was a programme — a programme full of IF-THEN rules: IF the transaction is more than 3× the average amount AND it is from a new location THEN flag it. That is AI."
7. Get ready to use AI Awareness Introduction Cards. Read together.

### DESIGN — Adaptive Response Design Sheet (10 min)
8. Get ready to use Real-World AI Connection Cards. Groups have 2 minutes to read all 4 and discuss: "Is this really just IF-THEN logic? Or is there something more?"
9. Bridge: "Today we add ONE adaptive response to our programme. One IF-THEN based on the score. It is a tiny step — but it is the same logic that powers the most advanced AI on earth."
10. Groups complete the Adaptive Response Design Sheet.
11. "When our score is BELOW ___, the character should ___ (e.g. grow slowly, play a gentle sound, show a sad face animation)."
12. "When our score is AT OR ABOVE ___, the character should ___ (e.g. spin fast, play a fanfare, grow to maximum)."
13. The threshold number must be meaningful: "At what score does the game FEEL different? At what score has the player earned the better response?"
