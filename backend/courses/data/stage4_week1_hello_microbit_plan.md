# Lesson 1: Hello Micro:bit – Meet Your New Tool

**Duration:** 60 minutes (split across Week 1 Lesson 1 start + Lesson 2 finish)  
**Term / Week:** Term 1 · Week 1  
**Age Range:** 8–10 years  
**Group Size:** 8 learners (pair programming, 4 pairs)  
**Hardware:** BBC Micro:bit v2, USB cable, shared laptops  
**Bloom's:** L2 Understanding  
**NCDC Ref:** Uganda NCDC P4 – Literacy Strand: Vocabulary & Reading; Numeracy Strand: Patterns & Coordinates  
**Cambridge:** Cambridge Primary Computing 0845 – Stage 4: Understanding how digital devices work; Inputs and outputs  
**DDD Phase:** DESIGN – Learners explore the Micro:bit interface and design their first LED output  

**Big Idea:** Every digital device has inputs and outputs. A Micro:bit is a tiny computer that reads inputs (buttons, sensors) and produces outputs (LED display, sound).

## Learning Objectives

- Unbox and connect a BBC Micro:bit v2 to a laptop via USB without adult help
- Open Microsoft MakeCode in a browser and navigate to the block editor
- Write and download a programme that scrolls their name on the Micro:bit LED display
- Programme Button A to show a happy face and Button B to show a sad face on the LED
- Define the words 'input' and 'output' in their own words with an example from today's lesson

## Materials and Preparation

- 4 BBC Micro:bit v2 kits with USB cables
- 4 shared laptops with internet access (makecode.microbit.org open)
- Printed Micro:bit interface map (A4 per pair) – labelled: LED matrix, Button A, Button B, USB port, edge connector
- Vocabulary card set: algorithm, input, output, variable, debug (one set per pair)
- Printed 5×5 grid worksheet (one per learner) for coordinate activity
- Facilitator device + projected screen or large TV

## Cross-Curricular Links

**English:** Vocabulary in context: input, output, algorithm – read definitions on cards and match each word to an example observed during activities. Learners use each word correctly in a sentence by end of session.

**Maths:** Explore the 5×5 LED grid using x-y coordinates. Count total pixels (25). Map the letter 'A' on the grid – how many pixels light up? Introduce coordinate notation (x, y).

## Lesson Structure

### HOOK – What Is a Micro:bit? (10 min)

1. Show a pre-loaded Micro:bit displaying a scrolling name. Ask: "What is this device? What do you think it can do?"
2. Play 'Input or Output?' – facilitator names actions (pressing a button, lighting an LED, detecting temperature). Learners call out: INPUT or OUTPUT.
3. Distribute vocabulary card sets. Pairs match each word (algorithm, input, output, variable, debug) to the example card. Review answers together.
4. Show projected MakeCode screen. Point to: block editor, simulator, download button, device name. Learners locate same features on their interface map.

### DESIGN – Plan Your Programme First (10 min)

5. Pairs receive the 5×5 grid worksheet. Task: shade the squares that represent the letter of your first initial. Count the shaded squares.
6. Discuss: "Your shaded grid IS your algorithm – a plan before you code."
7. Pairs write one sentence: "When I press Button A, the Micro:bit will ______. When I press Button B, it will ______."
8. Facilitator circulates – confirm every pair has a written plan before tablets are opened.

### DELIVER – Open MakeCode and Build (25 min)

9. Pairs connect Micro:bit via USB. Driver opens makecode.microbit.org in browser (or offline MakeCode app). Navigator reads from the interface map.
10. Step 1 (5 min): Open a new project. In the simulator, drag 'on start' block → 'show string' → type your name. Download to the device. Does the name scroll on the LED?
11. Step 2 (8 min): Add 'on button A pressed' block → 'show icon' (happy face). Add 'on button B pressed' block → 'show icon' (sad face). Download and test.
12. Step 3 (7 min): Swap Driver and Navigator roles. New Driver must explain what each block does to their partner before pressing Download.
13. Step 4 (5 min): Extension – can you change Button A to show your initial instead of a smiley face?

### DISCOVER – Share and Reflect (10 min)

14. Each pair demonstrates their Micro:bit to the class: Driver holds the device, Navigator explains one block aloud using correct vocabulary.
15. Facilitator asks 3 learners: "Point to an INPUT on your Micro:bit. Point to an OUTPUT. What is the algorithm for your Button A programme?"
16. Reflection: learners hold up 1 finger (easy), 2 fingers (medium), 3 fingers (hard) for: connecting USB / opening MakeCode / downloading programme.
17. Teaser: "Next week, we will READ someone else's code and predict what it does before running it – just like reading a book!"

### WRAP-UP – Save and Disconnect (5 min)

18. Facilitator demonstrates: unplug USB safely. Learners do the same and return kits to the kit box.
19. Each learner ticks their worksheet: Name scrolled on LED / Button A works / Button B works.
20. Collect and store all kits. Close MakeCode tabs.

## Assessment

**Formative (During):** Observation checklist: Can learner connect Micro:bit via USB? (Yes/Partially/Not yet). Can learner define 'input' and 'output' with an example? (oral check). Name scrolling on LED + button faces working (screen observation).

**Exit Assessment:** Oral exit check: facilitator asks each learner to say one sentence using the word 'input' and one using 'output'. Facilitator records on group checklist.

**Differentiation:** Support: Pre-load MakeCode with the 'on start / show string' block already placed. Extension: Learner programmes Button A+B pressed simultaneously to show a star icon.

## Key Vocabulary

algorithm · input · output · variable · debug · LED · programme · MakeCode · download · simulator

**Safeguarding Note:** Ensure learners do not programme personal surnames, phone numbers, or home addresses as scrolling text. Use first names or fictional names only.
