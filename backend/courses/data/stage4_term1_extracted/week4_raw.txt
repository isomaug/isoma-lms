Number card sets (10 cards: 4, 17, 8, 31, 26, 12, 5, 29, 20, 3) per pair
Scenario text cards: 'If a student scores above 50, they pass. Otherwise, they repeat.' (3 scenarios per pair)
Debug challenge sheet (printed) – MakeCode programme with 2 deliberate errors

Facilitator device + projected screen
Pairs receive 10 number cards. Task: sort them from smallest to largest. Ask: 'How did you decide which card goes first? You were using comparison logic!'
Facilitator gives a rule: 'Any card larger than 15 goes to the left pile. Smaller or equal goes to the right pile.' Pairs sort accordingly.
Reframe: "You just ran an if/else statement! IF the number > 15, put LEFT. ELSE put RIGHT. This is exactly what code does."
Show 3 scenario cards. Pairs read and write the if/else logic on their template sheet. Share one with the class.
Distribute plain English template sheets. Task: write 3 if/else statements for today's temperature programme. Example: 'If the temperature is greater than 25°C, show a tick. Otherwise, show a cross.'
Maths check: review comparison operators together. Ask: 'Greater than 25 – write it as a symbol.' (> 25). 'Less than or equal to 20?' (≤ 20).
Pairs share their written statements. Facilitator checks language is precise before coding begins.
Introduce Boolean: 'When the condition is true, one thing happens. When false, another happens. There are only two options – that is Boolean logic.'
Step 1 – Simple if/else (8 min): Open MakeCode. Use 'Logic' category → 'if/else' block. Inside: 'if temperature > 25 → show icon (tick); else → show icon (cross)'. Add this to 'on button A pressed'. Download and test. (Hold Micro:bit to test – temperature should read room temperature ~25°C).
Step 2 – Nested Condition (8 min): Expand to nested: 'if temp > 30 → sun icon; else if temp > 20 → tick icon; else → sad face'. Download and test. Facilitator demonstrates with a warm hand on the sensor.
Step 3 – True/False Quiz (5 min): Build a quiz: 'on start → show question (e.g. '5 > 3?') → if Button A (True) → show tick; if Button B (False) → show cross'. Programme a second question.
Step 4 – Debug Challenge (4 min): Distribute debug challenge sheet. Pairs identify and fix the 2 bugs in the printed code, then build the corrected version in MakeCode.
Each pair demonstrates their temperature programme. Partner explains every condition in plain English using the template: 'If [condition], then [action], otherwise [action].'
Facilitator asks 3 learners: 'What does Boolean mean? What are the two Boolean values? What symbol means greater than?'
Maths task: 'From the number cards, find all numbers that are greater than 10 AND less than 25.' Pairs circle on their sheets.
Teaser: "Next week we will connect the temperature sensor to a data table and a line graph – and find the MEAN temperature from 6 readings!"

ASSESSMENT
Formative (During) | Plain English if/else sheets collected and checked for correct condition structure. Temperature programme observed: does it correctly show tick/cross based on sensor reading? Debug challenge: were both errors identified and corrected?
Exit Assessment | Coded quiz with at least 2 if/else conditions submitted and runs correctly. Learner explains each condition in plain English to facilitator – scored: Clear / Partially clear / Needs support.
Differentiation | Support: Provide the if/else block pre-built in MakeCode; learner only changes the condition value and the icon displayed. Extension: Learner programmes a 3-condition nested system using Button A+B pressed together as a third input.
