Big Idea
Loops let a computer repeat instructions without us writing them again and again. A loop is like a chorus in a song – it plays the same part over and over.
Key ILO
ILO 2.1 – Write and read block-based Micro:bit programmes in MakeCode, including correct use of on start, forever, loops, and input events.
LEARNING OBJECTIVES
#
Objective
1
Act out a loop physically before coding it (unplugged warm-up)
2
Code a 'for' loop in MakeCode that counts from 1 to 10 and displays each number on the LED matrix
3
Code a 'while' loop that flashes the LED matrix until Button A is pressed
4
Create a list of 5 numbers and use a loop to display each one on the LED
5
Explain what 'iteration' means in their own words
6
Calculate: if a loop runs 7 times and adds 3 each iteration, what is the final total?
Materials & Preparation
4 BBC Micro:bit v2 kits + USB cables
4 shared laptops with MakeCode open
Rope or tape on floor to mark a 'loop track' (for unplugged warm-up)
Number cards 1–10 (one set per pair, printed on card)
'Loop Step-by-Step' instruction worksheet (A4 per pair)
Squared paper for number pattern recording (A5 per learner)
Facilitator device + projected screen
Vocabulary cards: 'for loop', 'while loop', 'iteration', 'list/array', 'index'
Cross-Curricular Links
English Literacy
Sequence writing: learners write step-by-step instructions for a loop activity. Number each step. Swap with a partner to follow their instructions exactly. Vocabulary: use 'first', 'then', 'repeat', 'until', 'finally' as instruction connectives.
Mathematics
Number patterns: count in 2s, 5s, and 10s generated by for loops. If a loop runs 7 times and adds 3 each time, what is the final total? Skip counting. If one loop takes 4 seconds, how long will 5 loops take? Introduce multiplication link.
LESSON STRUCTURE
Step
Activity
HOOK – Act Out a Loop (10 min)
1
Unplugged activity: mark a loop track on the floor with tape. One learner is the 'robot'. Facilitator says: 'Walk the track. Do NOT stop until I say STOP.' Learner walks the loop 5 times.
2
Ask the class: 'What did our robot just do? How many times did it repeat?' Introduce the word 'iteration' – one complete trip around the track = one iteration.
3
Show the same loop in MakeCode on screen (a 'forever' block with 'show number' inside). Ask: 'Can you spot the loop in this code?'
4
Learners write their own 3-step loop instruction on their worksheet using number words: 'Step 1: ___. Step 2: ___. Step 3: Repeat from Step 1.'
DESIGN – Plan the Loop Programme (10 min)
5
Pairs plan their for loop on the 'Loop Step-by-Step' worksheet: What will the loop count from and to? What will it show on the LED? How many iterations?
6
Pairs write the loop as a numbered instruction list and swap with another pair to check. Does the instruction make sense to follow?
7
Facilitator introduces the MakeCode 'for' loop block on screen. Point out the variable 'index' – explain: 'This is like the page number in a book. It tells you where you are in the loop.'
DELIVER – Code Three Loops (30 min)
8
Distribute Micro:bits and laptops. Assign Driver and Navigator roles.
9
Task 1 – For Loop (10 min): Code a for loop from 0 to 9 (10 iterations) that shows each number on the LED matrix with a short pause. Download and run. Does it count 1 to 10?
10
Task 2 – While Loop (10 min): Code a 'while button A is not pressed' loop that flashes a heart icon on the LED. Download and run. Press Button A to stop. Ask: 'What is the CONDITION that ends the loop?'
11
Task 3 – List/Array (10 min): Create a list of 5 favourite numbers. Use a for loop to display each number from the list in sequence. Download and run. SWAP Driver and Navigator. New Driver explains the code block by block.
12
Pattern challenge (extension): use a loop to scroll the 5-times table (5, 10, 15, 20, 25) across the LED display.
DISCOVER – Share and Debug (8 min)
13
Two pairs share their loop programmes with the class. They must explain: 'Our loop starts at ___, ends at ___, and repeats ___ times.'
14
Facilitator presents a broken loop on screen (missing pause block causes display to flicker too fast). Pairs discuss: 'What is wrong? How do we fix it?' One pair offers a fix.
15
Maths connection: facilitator asks: 'If our loop runs 7 times and adds 3 each iteration starting from 0, what is the total?' Pairs calculate on squared paper. Answer: 21.
WRAP-UP – Save and Reflect (2 min)
16
Rename project 'Week3_[Name]'. Disconnect and return Micro:bit.
17
Exit sentence on worksheet: 'A loop saves time because ___. My loop repeated ___ times today.'
Assessment
Formative (During)
Observation: Does the for loop count correctly and display each number? (screen observation)
Can learner explain 'iteration' in their own words? (oral check)
While loop stops on Button A press? (functionality check)
Exit Assessment
Learner demonstrates their for loop to the facilitator and explains: ① what 'index' means ② how many iterations it runs ③ what would change if they changed the end number. 3 points – recorded per learner.
Differentiation
Support: Provide a half-completed MakeCode programme where learner only fills in the start and end values of the for loop. Extension: Write a loop that counts backwards from 10 to 1 and explains the change in code to a partner. Programme the 5-times table to scroll on the LED.
Key Vocabulary
for loop · while loop · iteration · index · list · array · repeat · condition · count · pattern
