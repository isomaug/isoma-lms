# Week 3 - Lesson 2

## Session length
**About half of this week's plan** (finish what you started in Lesson 1)

## Finish the week
- Act out a loop physically before coding it (unplugged warm-up)
- Code a 'for' loop in MakeCode that counts from 1 to 10 and displays each number on the LED matrix
- Code a 'while' loop that flashes the LED matrix until Button A is pressed
- Create a list of 5 numbers and use a loop to display each one on the LED
- Explain what 'iteration' means in their own words
- Calculate: if a loop runs 7 times and adds 3 each iteration, what is the final total?

## Continue

### DELIVER – Code Three Loops (30 min)
1. Task 1 – For Loop (10 min): Code a for loop from 0 to 9 (10 iterations) that shows each number on the LED matrix with a short pause. Download and run. Does it count 1 to 10?
2. Task 2 – While Loop (10 min): Code a 'while button A is not pressed' loop that flashes a heart icon on the LED. Download and run. Press Button A to stop. Ask: 'What is the CONDITION that ends the loop?'
3. Task 3 – List/Array (10 min): Create a list of 5 favourite numbers. Use a for loop to display each number from the list in sequence. Download and run. Continue with the next steps yourself. New Driver explains the code block by block.
4. Pattern challenge (extension): use a loop to scroll the 5-times table (5, 10, 15, 20, 25) across the LED display.
### DISCOVER – Share and Debug (8 min)
5. Two you share their loop programmes with yourself. They must explain: 'Our loop starts at ___, ends at ___, and repeats ___ times.'
6. You presents a broken loop on screen (missing pause block causes display to flicker too fast). You discuss: 'What is wrong? How do we fix it?' One pair offers a fix.
7. Maths connection: you ask: 'If our loop runs 7 times and adds 3 each iteration starting from 0, what is the total?' You calculate on squared paper. Answer: 21.
### WRAP-UP – Save and Reflect (2 min)
8. Rename project 'Week3_[Name]'. Disconnect and return Micro:bit.
9. Exit sentence on worksheet: 'A loop saves time because ___. My loop repeated ___ times today.'

## Check your understanding
- Formative (During)
- Observation: Does the for loop count correctly and display each number? (screen observation)
- Can learner explain 'iteration' in their own words? (oral check)
- While loop stops on Button A press? (functionality check)
- Exit Assessment
- Learner demonstrates their for loop to the you and explains: ① what 'index' means ② how many iterations it runs ③ what would change if they changed the end number. 3 points – recorded for you.
- Differentiation
- Support: Provide a half-completed MakeCode programme where learner only fills in the start and end values of the for loop. Extension: Write a loop that counts backwards from 10 to 1 and explains the change in code to a partner. Programme the 5-times table to scroll on the LED.
