# Week 3 - Lesson 1

## Session length
**About half of this week's plan** (you will finish in Lesson 2)

## Today you will learn
- Act out a loop physically before coding it (unplugged warm-up)
- Code a 'for' loop in MakeCode that counts from 1 to 10 and displays each number on the LED matrix
- Code a 'while' loop that flashes the LED matrix until Button A is pressed
- Create a list of 5 numbers and use a loop to display each one on the LED
- Explain what 'iteration' means in their own words
- Calculate: if a loop runs 7 times and adds 3 each iteration, what is the final total?

## Big idea
Loops let a computer repeat instructions without us writing them again and again. A loop is like a chorus in a song – it plays the same part over and over.

## What you need
- 4 BBC Micro:bit v2 kits + USB cables
- 4 shared laptops with MakeCode open
- Rope or tape on floor to mark a 'loop track' (for unplugged warm-up)
- Number cards 1–10 (one set for you, printed on card)
- 'Loop Step-by-Step' instruction worksheet (A4 for you)
- Squared paper for number pattern recording (A5 for you)
- A computer or screen to follow along
- Vocabulary cards: 'for loop', 'while loop', 'iteration', 'list/array', 'index'

## Links to English and Maths
- **English:** Sequence writing: you write step-by-step instructions for a loop activity. Number each step. Swap with a partner to follow their instructions exactly. Vocabulary: use 'first', 'then', 'repeat', 'until', 'finally' as instruction connectives.
- **Maths:** Number patterns: count in 2s, 5s, and 10s generated by for loops. If a loop runs 7 times and adds 3 each time, what is the final total? Skip counting. If one loop takes 4 seconds, how long will 5 loops take? Introduce multiplication link.

## Let's begin

### HOOK – Act Out a Loop (10 min)
1. Unplugged activity: mark a loop track on the floor with tape. One learner is the 'robot'. You says: 'Walk the track. Do NOT stop until I say STOP.' Learner walks the loop 5 times.
2. Ask yourself: 'What did our robot just do? How many times did it repeat?' Introduce the word 'iteration' – one complete trip around the track = one iteration.
3. Show the same loop in MakeCode on screen (a 'forever' block with 'show number' inside). Ask: 'Can you spot the loop in this code?'
4. You write their own 3-step loop instruction on their worksheet using number words: 'Step 1: ___. Step 2: ___. Step 3: Repeat from Step 1.'
### DESIGN – Plan the Loop Programme (10 min)
5. You plan their for loop on the 'Loop Step-by-Step' worksheet: What will the loop count from and to? What will it show on the LED? How many iterations?
6. You write the loop as a numbered instruction list and swap with another pair to check. Does the instruction make sense to follow?
7. Look at the MakeCode 'for' loop block on screen. Point out the variable 'index' – explain: 'This is like the page number in a book. It tells you where you are in the loop.'
### DELIVER – Code Three Loops (30 min)
8. Get ready to use Micro:bits and laptops. Work through the steps yourself.
