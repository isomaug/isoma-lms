# Week 2 - Lesson 1

## Session length
**About half of this week's plan** (you will finish in Lesson 2)

## Today you will learn
- Trace a provided MakeCode programme with nested if/else conditions on paper and write the predicted output for 3 different inputs
- Explain the difference between AND (both conditions must be true) and OR (at least one condition must be true) using a real-world example
- Code a programme that uses AND: if temperature > 25 AND button A is pressed -> show sun icon; otherwise -> show moon icon
- Code a programme that uses OR: if button A is pressed OR the Micro:bit is shaken -> show star icon; otherwise -> show dot
- Design a 3-decision system using at least 2 sensors and one Boolean operator, documented in a logic flow diagram on paper before coding
- Identify and fix 2 logic errors in a provided broken programme using the trace method

## Big idea
One condition decides between two outcomes. Two conditions connected by AND or OR decide between many outcomes. Tracing code on paper — like a detective following clues — lets you predict what a programme will do before you ever run it.

## What you need
- 4 BBC Micro:bit v2 kits + USB cables
- 4 shared laptops with MakeCode open
- Programme trace worksheet (A4 for you) – printed MakeCode screenshot of a nested if/else programme; 3 rows: Input | Predicted Output | Actual Output
- Logic flow diagram template (A4 for you) – blank diamond-box flowchart with space for conditions and outcomes
- Broken code worksheet (A4 for you) – printed MakeCode screenshot with 2 highlighted logic errors
- Vocabulary cards: 'AND', 'OR', 'Boolean operator', 'trace', 'condition', 'nested', 'multi-input', 'true', 'false'
- A computer or screen to follow along
- Sticky notes for logic predictions

## Links to English and Maths
- **English:** Reading comprehension of code as text: you read the trace worksheet programme as if it were a story — 'First this happens, then this, then this.' Answer 4 structured questions: What is the first condition checked? What happens if it is false? What two conditions must BOTH be true for the sun icon to appear? Write one sentence explaining what AND means in plain English. The logic flow diagram is treated as a piece of structured writing — each decision box must contain a complete condition written as a full sentence.
- **Maths:** Boolean logic and truth tables: you complete a 4-row truth table for AND (T+T=T, T+F=F, F+T=F, F+F=F) and OR (T+T=T, T+F=T, F+T=T, F+F=F). Comparison operators revisited: < > = ≠ ≤ ≥. Two-condition sorting: given a list of 10 numbers, find all numbers that satisfy BOTH conditions simultaneously (e.g. >5 AND <15). How many numbers satisfy either condition using OR? Count and compare the two sets.

## Let's begin

### HOOK – Trace the Code (10 min)
1. Get ready to use the programme trace worksheet face-down. Ask: 'Do NOT look yet.' Then flip over. Set a 2-minute silent reading timer. You read the programme code on the sheet without touching a computer.
2. You write their prediction for Input 1 on a sticky note: 'If temperature is 30°C and Button A is not pressed, what shows on the LED?' Collect predictions. Read 3 aloud. Bridge: 'Let's see if our detective work was right — but first let's learn the new tools.'
3. Introduce AND and OR with a physical activity: 'Stand up IF you are wearing something blue AND you have a pencil.' Count who stands. 'Now stand up IF you are wearing something blue OR you have a pencil.' Count again. Ask: 'Why did more people stand for OR?' Guide to the key distinction.
4. Write on board: AND = stricter (both must be true). OR = broader (either is enough). You copy into vocabulary cards.
### DESIGN – Logic Flow Diagram (10 min)
5. Get ready to use logic flow diagram templates. You design their 3-decision system on paper FIRST: 'If ___ AND ___ -> outcome A. Else if ___ OR ___ -> outcome B. Else -> outcome C.' Each decision diamond must be filled before laptops open.
6. You complete the truth table on the back of the worksheet: AND column (4 rows) and OR column (4 rows). You checks: 'When is AND true? When is OR false?' Confirm understanding before moving to code.
7. Two-condition sorting exercise: Read 10 numbers aloud (3, 7, 11, 4, 18, 6, 2, 14, 9, 20). You circle numbers that satisfy both conditions on their worksheet: greater than 5 AND less than 15. Then circle numbers for OR: greater than 5 OR less than 15.
### DELIVER – Code Three Systems (30 min)
8. Get ready to use Micro:bits and laptops. Assign Driver and Navigator.
