# Week 1 - Lesson 2

## Session length
**About half of this week's plan** (finish what you started in Lesson 1)

## Finish the week
- Define 'variable' in their own words and give one example of where variables are used in everyday life
- Create and set a numeric variable in MakeCode ('score', 'count', or a name they choose) and display its value on the LED matrix
- Modify the variable's value using Button A (increment by 1) and Button B (decrement by 1), displaying the updated value each time
- Set the radio group to a shared number and use 'radio send number' to transmit the variable's current value to a partner's Micro:bit
- Use 'on radio received' on the partner Micro:bit to display the received value on the LED matrix
- Explain in plain English: 'What is a variable?', 'What does radio send do?', and 'What does radio receive do?' — one sentence each

## Continue

### DELIVER – Code Both Sides (30 min)
1. Part 2 – Add radio send (8 min): inside each button event, AFTER updating the variable, add 'radio send number score'. Set radio group to 1. Re-download to Micro:bit 1.
2. Part 3 – Receiver programme (8 min): new project on same laptop. On radio received (receivedNumber) -> show number receivedNumber. Set radio group to 1. Download to Micro:bit 2.
3. Part 4 – Test the link (4 min): both Micro:bits connected. Press Button A on Micro:bit 1 — does the number appear on Micro:bit 2? Continue with the next steps yourself. New Driver explains each block aloud before any change is made.
### DISCOVER – Investigate and Reflect (8 min)
4. Challenge: 'Change the radio send to send a STRING (a word) instead of a number. What block do you need? What changes on the receiver side?' You investigate in MakeCode for 3 minutes.
5. Two you share their radio results with yourself. Each explains: 'Our variable was called ___. Micro:bit 1 sent ___ and Micro:bit 2 showed ___.'
6. Maths debrief: Ask yourself — 'Start at 0. Press A five times and B twice. What is the value now?' You calculate: 5 − 2 = 3. 'What if you pressed B once more?' Answer: 2. Record on the number-line worksheet.
7. Vocabulary consolidation: you write three sentences on their sticky-note exit ticket — one for 'variable', one for 'radio send', one for 'radio receive'.
### WRAP-UP – Save and Reflect (2 min)
8. Rename both MakeCode projects: 'T2W1_[Name]_Sender' and 'T2W1_[Name]_Receiver'. Disconnect both Micro:bits and return to kit box.
9. Collect exit-ticket sticky notes and planning sheets. You records which you demonstrated a working radio link on the assessment record sheet.

## Check your understanding
- Formative (During)
- Observation: Does the variable change correctly on button presses and display on the LED? (functionality check — Micro:bit 1)
- Does Micro:bit 2 display the received number when Micro:bit 1 sends it? (radio link functionality check)
- Can learner define 'variable' and 'radio group' in one sentence each? (oral check)
- Planning sheet completed with both sender and receiver programmes written in plain English before coding? (worksheet check)
- Exit Assessment
- Sticky-note exit ticket: 3 sentences — ① 'A variable is…' ② 'Radio send means…' ③ 'Radio receive means…'. Collected by you. Assessment criteria: each sentence must use the word in context correctly, not just repeat the definition from the card. 3 points for you.
- Differentiation
- Support: Pre-build the variable and button blocks so learner only needs to add the radio send and radio group blocks. Provide a colour-coded planning sheet where Sender blocks are blue and Receiver blocks are green. Extension: Programme a two-player reaction game — Micro:bit 1 sends a random number when shaken; Micro:bit 2 displays it and the player must press Button A if the number is greater than 5, or Button B if not. Add a win/lose icon based on the response.

## Stay safe
Safeguarding Note: Radio programmes broadcast to all Micro:bits on the same group number. Ensure you do not send personal names, surnames, or identifying data via the radio block. Use only numbers or agreed neutral words (e.g. 'hello', 'go') in radio transmissions during the session.

3. Close the laptop and pack up safely.
