# Week 5 - Lesson 2

## Session length
**About half of this week's plan** (finish what you started in Lesson 1)

## Finish the week
- Enable the MakeCode Bluetooth extension and explain why enabling Bluetooth disables the radio module (they share the same antenna hardware on the Micro:bit v2)
- Use the Bluetooth extension to display the Micro:bit's name and UUID on the LED matrix so a paired device can identify it
- Programme the Micro:bit to broadcast a live temperature reading over Bluetooth using the 'bluetooth temperature service' block
- Pair a phone or tablet with the Micro:bit using the official Micro:bit app (iOS/Android) and confirm the temperature reading appears on the paired device screen
- Create a comparison table: Radio vs. Bluetooth — 4 rows comparing range, number of connected devices, setup complexity, and real-world use case
- Write a 4-sentence technical explanation: what Bluetooth is, how it differs from radio, what the Micro:bit uses it for, and one real-world application where Bluetooth would be preferred over radio

## Check your understanding
- Formative (During)
- Observation: Does the Bluetooth programme show the tick icon when paired and the cross icon when disconnected? (connection event handlers check)
- Does a live temperature reading appear on the paired phone/tablet via the Micro:bit app? (Bluetooth broadcast functionality check)
- Comparison table completed with all 4 rows filled for both Radio and Bluetooth columns? (worksheet check)
- 4-sentence technical explanation written with the words 'paired', 'wireless', 'range', and 'protocol' all present? (vocabulary-in-use check)
- Exit Assessment
- Ask yourself you: ① 'Why does enabling Bluetooth disable the radio on the Micro:bit?' ② 'What was the temperature reading on the paired device — was it higher or lower than expected? Why?' ③ 'Name one situation where you would choose radio over Bluetooth, and one where you would choose Bluetooth over radio.' 3 points for you — recorded on assessment log as the week's formally weighted artifact.
- Differentiation
- Support: Pre-pair the Micro:bit with the phone before the session so learner only needs to build the programme and confirm the temperature reading appears. Reduce the comparison table to 2 rows (range and use case only). Provide sentence completion frames for all 4 technical explanation sentences. Extension: Programme the Micro:bit to broadcast BOTH temperature AND accelerometer strength alternately over Bluetooth using a forever loop that switches between bluetooth temperature service and bluetooth accelerometer service every 5 seconds. Write a paragraph comparing what the app displays for each service and explain what each reading represents physically.

## Stay safe
Safeguarding Note: Bluetooth pairing requires the Micro:bit to be in pairing mode — this involves holding both buttons simultaneously, which must be modelled by the you before you attempt it. Ensure no learner you their Micro:bit to a personal device without you supervision. All phones and tablets used are you-owned programme devices. You must not download or access any apps beyond the official Micro:bit app. Bluetooth communications in this session broadcast sensor data only — no personal data, names, or identifying information is transmitted.
