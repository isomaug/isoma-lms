# Week 6 - Lesson 1

## Session length
**About 30 minutes** (you will finish this week in Lesson 2)

## Today you will learn
- Write a 3-scene story plan: Setting (Scene 1), Conflict/Problem (Scene 2), Resolution (Scene 3)
- Identify what LED animation represents each scene and which button press triggers the next scene
- Code each scene in MakeCode, triggered by Button A (next scene) and Button B (restart story)
- Test the full 3-scene story, confirm transitions, and revise errors
- Calculate total animation duration and express Scene 1 as a fraction of the total
- Present the story using the written plan, explaining what each scene shows on the LED

## Big idea
An algorithm is a plan written before you code. A story has a beginning, a problem, and a resolution – just like a programme has a start, a decision, and an outcome. Today your story IS your algorithm.

## What you need
- 4 BBC Micro:bit v2 kits with USB cables
- Story plan template – Scene 1 / 2 / 3 with story text, LED animation, duration, button trigger
- LED icon reference card (heart, duck, house, snake, arrow, and others)
- Peer review 'One Star, One Wish' cards
- A screen or device to show a sample 3-scene animation

## Links to English and Maths
- **English:** Narrative writing: Setting, Conflict/Problem, Resolution. Each scene needs at least one sentence. The written plan is assessed. Present the story orally using the plan.
- **Maths:** Timing and fractions: assign duration in seconds to each scene. Total duration = sum. Express Scene 1 as a fraction of the total (for example 4/15).

## Let's begin

### HOOK – Stories and Programmes
1. Watch a 3-scene Micro:bit animation (for example heart → snake → house). What story could this tell?
2. Story structure: Setting → Conflict/Problem → Resolution.
3. Example: 'One morning a small bird was singing… Suddenly a storm arrived… Finally the sun returned.' Identify each part.
4. Maths: If Scene 1 lasts 4 seconds and Scene 2 lasts 6 seconds, what fraction of the first two scenes is Scene 1? (4/10 = 2/5)

### DESIGN – Write Your Story Plan First
5. Write the story text **before** choosing LED icons. The story drives the code.
6. For each scene: choose an LED icon, choose duration (3–8 seconds), note which button triggers the next scene.
7. Calculate total duration. Express Scene 1 as a fraction of the total.
8. Check: Does Scene 1 set the scene? Is there a clear problem in Scene 2? Is it resolved in Scene 3?

### DELIVER – Code the story (start)
9. **Step 1:** Create a variable `scene` set to 0 on start.
10. **Step 2:** On button A pressed → change scene by 1 → if scene = 1 / 2 / 3 show the matching icon and pause for that scene's duration. Download and test.
