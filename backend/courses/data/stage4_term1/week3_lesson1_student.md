# Week 3 - Lesson 1

## Session length
**About 30 minutes** (you will finish this week in Lesson 2)

## Today you will learn
- Explain what a loop is and act out a loop activity physically before coding
- Write a step-by-step loop algorithm on paper and number each step
- Code a 'for' loop in MakeCode that counts from 1 to 10 on the LED display
- Code a 'while' loop that flashes the LED until a button is pressed
- Create a list of 5 numbers and use a loop to display each one
- State what 'iteration' means using your own words

## Big idea
A loop is an instruction that repeats automatically. Computers are very good at doing the same thing many times – loops make that possible without writing the same block over and over.

## What you need
- 4 BBC Micro:bit v2 kits with USB cables
- Loop algorithm worksheet (A4) – blank numbered steps template
- Number pattern cards (1–10, 2–20 by 2s, 5–50 by 5s)
- Printed 'What Is a Loop?' reference card
- A screen or device to show MakeCode

## Links to English and Maths
- **English:** Sequence writing: write step-by-step instructions for a loop activity on paper. Number each step. Follow the instructions exactly – were they clear and complete?
- **Maths:** Number patterns: loops generate sequences. Count in 2s, 5s, 10s using for loops. Identify the pattern rule. Challenge: if a loop runs 7 times and adds 3 each time starting from 0, what is the final value? (Answer: 21).

## Let's begin

### HOOK – Act Out a Loop
1. Clap 5 times and count. That is a loop – the same action repeated a set number of times.
2. Try a physical loop: jump (or clap) a given number of times, then stop. Repeat with new numbers.
3. Think: what if you jump forever until STOP? That is a **while** loop – it continues until a condition is met.
4. Look at number pattern cards. What is the rule? How could a computer generate this automatically?

### DESIGN – Write Your Algorithm First
5. On the loop algorithm worksheet, write instructions for: count from 1 to 10 and show each number on the LED. Number every step.
6. Check your instructions: What is the starting number? Ending number? What changes each step?
7. Key word: the number of times a loop runs is the number of **iterations**. Say it: i-ter-a-tions.

### DELIVER – Code loops (start)
8. **Step 1 – For loop:** In MakeCode, open Loops → `for index from 0 to 4` (or count to 10). Inside: show number. Download. Do numbers appear on the LED?
9. **Step 2 – While loop:** Build `while button A is not pressed` → show icon → pause → clear screen → pause. Download. Does the LED flash until Button A is pressed?
