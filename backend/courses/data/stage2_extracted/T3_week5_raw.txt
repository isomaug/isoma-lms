Open the collaborative integrated project from Lesson 19.
Step 1 — Conditional logic trace (5 min): Complete the trace worksheet with the planned threshold value. "If score = 1 → which branch? If score = 3 → which branch? If score = 5 → which branch?" Confirm understanding before coding.
Step 2 — Build Branch 1 (10 min): After the main game mechanic, add the conditional check: IF score < threshold → play Branch 1 response. Test with a score below threshold. Does Branch 1 fire? Record in trace worksheet.
Step 3 — Build Branch 2 (8 min): Add ELSE (or second trigger): IF score ≥ threshold → play Branch 2 response. Test with a score at and above threshold. Does Branch 2 fire correctly?
Step 4 — Full game run with adaptive response (5 min): Play the game from start to finish twice — once reaching the low-score response, once reaching the high-score response. Confirm both branches work. Record on the Adaptive Response Design Sheet: "Branch 1 tested: YES/NO. Branch 2 tested: YES/NO."
Groups run both branches for the adjacent group. Adjacent group answers: "Does this programme seem to KNOW something about the player?"
Class discussion: "We just made our programme seem intelligent. It responds differently based on performance. Is it actually intelligent? What is missing for it to be truly AI?"
Key insight: "It is intelligent in a LIMITED way. It knows exactly two things: score < 3 or score ≥ 3. Real AI learns new thresholds from data instead of having one fixed number. But the principle is identical."

Big Idea
AI is not magic — it is a very large, very fast collection of IF-THEN rules. The same logic you used to make a character respond to a tap is the same logic — at enormous scale — that drives voice assistants, recommendation engines, and medical diagnosis tools.

English
Explaining a technical concept to a non-specialist: learners must practise the sentence "AI is ___ because ___" until it is both accurate and accessible. The target audience for this explanation is "a grandparent who has never used a smartphone." This requires stripping out jargon and using analogies. Vocabulary: artificial intelligence, conditional, response, input, adaptive, pattern, scale, decision, intelligent, analogy.
Maths
Branching logic as a number line: "Score < 3" means the score is in the set {0, 1, 2}. "Score ≥ 3" means {3, 4, 5, …}. Learners complete: "If the game has a maximum score of 5, how many values are in the first branch? ___ How many in the second? ___" Introduction to set theory and inequality notation.

Full marks = clear analogy that accurately describes conditional branching.
Differentiation
Support: Reduce to one adaptive response only (one branch fires when score ≥ threshold; otherwise nothing happens). Extension: Design a THREE-branch response: score < 2 → response A; score 2–4 → response B; score ≥ 5 → response C. Implement all three, test all three, and connect each branch to a different level of achievement ("OK", "Good", "Amazing").
