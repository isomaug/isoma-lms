Define an algorithm as "a set of precise, step-by-step instructions to solve a problem or tell a story"
Create a 5-step story map algorithm using pictures and arrows showing a character's journey
Identify at least one error in a given "buggy" algorithm and suggest a correction
Implement the first 3 steps of the story map as Stack KIDI blocks and run the programme
4 tablets with Stack KIDI (new projects)
Algorithm Story Map template (A4 per learner) - 5 numbered panels with arrows between them
Block reference poster (movement, trigger, end blocks)
Printed "Buggy Algorithm" cards - 3 scenarios with deliberate ordering errors
Coloured pens for story map drawing
Class wall chart: "Algorithm = A plan with steps in the right order"
Facilitator reads a deliberately muddled recipe: "Put the bread on the plate. Spread the butter. Cut the bread. Get the bread from the bag." Ask: "What is wrong with this recipe?"
Learners suggest the correct order. Write steps on the board 1–4 in the right order.
Introduce the word ALGORITHM: "A recipe is an algorithm for cooking. Today we write an algorithm for a character in Stack KIDI."
Show the wall chart. Learners read aloud: "Algorithm = A plan with steps in the right order."
Distribute Story Map templates. Explain the 5 panels.
Task: "Plan a journey for your character. It starts at HOME, goes somewhere, does something, comes back."
Each panel must have: a drawing of what happens AND a direction word (forward/backward/turn/jump/spin).
Pairs share story maps with the pair next to them. Partner checks: "Does Step 2 come BEFORE Step 3? Does the order make sense?" Partners suggest one improvement.
Facilitator models their own 5-step story map on the projected screen: a character walking to school, turning left, finding a ball, spinning, returning home.
Introduce "Bug Hunt": facilitator shows a buggy algorithm on projected screen (Step 4 and Step 5 swapped). Ask: "What is wrong? How do we fix it?"
Distribute Buggy Algorithm cards (3 different scenarios).
Pairs identify the error on their card and write/draw the correction.
Share: one pair per scenario presents. Class votes: "Is their fix correct?"
Key teaching: "A bug is a mistake in an algorithm. Fixing bugs is called DEBUGGING."
Open Stack KIDI, new project. Name the character using the pair's team name.
Task: implement ONLY Steps 1, 2, and 3 from your story map as Stack KIDI blocks.
Step 1 → first block;
Step 2 → second block;
Step 3 → third block. Must start with the Green Flag trigger block.
Run the programme. Does it match the story map? If not - is it a bug in the code OR a bug in the story map? Fix whichever needs fixing.
Facilitator circulates with observation checklist:
① Green Flag trigger present
② 3 blocks in sequence
③ Sequence matches story map steps 1–3.
Each pair places story map on desk next to tablet.
Pairs walk around and look at 2 other pairs' work. They must find: one similarity and one difference from their own algorithm.
Whole class: "What did algorithms have in common?" Facilitator records responses on board.
Exit reflection: each learner completes the sentence: "An algorithm is ___."
Save projects. Collect tablets and story map sheets (kept in learner folders).
Preview: "Next lesson - we use LOOPS to make our character repeat actions!"

CROSS-CURRICULAR LINKS
English
Narrative structure: Beginning → Middle → End maps onto Algorithm Step 1 → Steps 2–4 → Step 5. Learners write the story map captions using a new verb in each panel (hop, spin, zoom, hide, wave). Vocabulary: algorithm, precise, instruction, sequence, plan.
Maths
Ordinal numbers: 1st step, 2nd step, 3rd step… Counting steps in an algorithm. Comparison: "My algorithm has 5 steps. My partner's has 4. How many more do I have?"
