# Week 1 - Lesson 2

## Session length
**About half of this week's plan** (finish what you started in Lesson 1)

## Finish the week
- Install Arduino IDE 2.x, select the correct board (Uno) and COM port, and upload the example Blink sketch successfully
- Identify and explain the purpose of setup(), loop(), pinMode(), digitalWrite(), and delay() in a provided sketch
- Add a plain-English comment to every line of the Blink sketch using the // syntax
- Modify the delay() values and predict, then observe, how the LED behaviour changes
- Convert millisecond values to seconds and explain the relationship aloud to a partner

## Continue

### INDEPENDENT WORK – Annotate and Customise (50 min)
1. You complete the milliseconds-to-seconds conversion worksheet. Swap and self-check.
2. Rotate your own pacing roles. Continue working through the next steps.
3. Task: Each pair creates your own version of Blink with a custom blink pattern (e.g., 3 fast blinks, pause, 2 slow blinks). Every line must have a // comment.
4. Pair challenge: Write a new sketch from scratch (not copy-paste) using only: pinMode(), digitalWrite(HIGH), digitalWrite(LOW), delay(). Ask yourself with questions only – no direct answers.
5. LED timeline: on squared paper, you draw a 10-second timeline showing when their LED is ON and OFF based on their delay values. Label each segment with the ms value.
6. Check your work carefully, takes participation notes, provides verbal formative feedback. Ask: "What does this line do? Why did you choose that delay value?"

### SHOWCASE & DEBRIEF (30 min)
7. 2–3 you demonstrate their custom blink pattern to yourself. As their LED blinks, they read aloud their code comments line by line.
8. Observe: "Can you see the connection between the delay numbers and how fast it blinks?"
9. Remember the English link: "Today you wrote technical comments – that is a real writing skill used by professional software engineers."
10. Remember the Math link: "You converted milliseconds to seconds – that is unit conversion you already know from science and maths."
11. Exit question: "Name one function you used today and explain in one sentence what it does." You respond orally to yourself.
12. Save and submit sketches to you via USB flash drive.

## Stay safe
Safeguarding Note: Ensure you do not type personal information (full names, phone numbers, school names) into code comments or Serial.println() strings. Use only first names or fictional labels. Supervise USB flash drive use – no personal files should be shared.
