🎯  Intended Learning Outcome (ILO)
💡  Big Idea
• ILO 3.2 — Apply variables, for loops, while loops, and user-defined functions to solve a mathematical problem computationally, demonstrating the connection between code structure and arithmetic sequence.
• A loop is a shortcut. Instead of writing the same instruction 10 times, you write it once and tell the computer how many times to repeat it — just like a numbered list of instructions.
📖  English Literacy Thread
🔢  Mathematics Thread
• Parallel structure activity: write a numbered list of instructions in English that mirrors the for loop exactly. Each numbered step = one loop iteration. "1. Print 7. 2. Print 14. 3. Print 21…" — then write the loop that does the same. Learners explain their loop structure to their partner verbally: "This is like the 7 times table because each time the loop runs, it adds 7."
• Times tables via for loops. Arithmetic sequences: first term, common difference, nth term. for(int i=3; i<=60; i+=3) — what is the first term? (3) Common difference? (3) Number of terms? (20). Sum of first 5 terms? Connect loop iteration count to multiplication.
Phase
Time
Activities & Facilitator Actions
1. HOOK
The Human Loop
20 min
• Physical activity: facilitator calls out "Print 2!" — learner says "2". "Print 4!" — "4"... up to 20. "That was YOU being a loop!"
• Ask: "How would you write that as instructions on paper?" Collect answers. Show how a for loop condenses this.
• Write on board: for(int i=2; i<=20; i+=2) — translate each part: i=2 is start, i<=20 is stop, i+=2 is step.
• Quick Math: given for(int i=3; i<=60; i+=3) — first term? (3). Common difference? (3). How many terms? (20). Class works this out together.
• Distribute Sequence Parallel worksheet. Explain the task: complete both columns so the English instructions exactly match the loop.
2. GUIDED ACTIVITY
Times Tables in Code
60 min
• Step 1 (15 min): Facilitator live-codes a for loop that counts 1 to 10, printing to Serial Monitor. Learners type along.
• Step 2 (20 min): Pair task — write a for loop that generates and prints the 7× times table. Expected output: 7, 14, 21… up to 70. One learner writes pseudocode first, other types the code.
• Step 3 (10 min): Verify, upload, open Serial Monitor. Check output. If incorrect — trace through the loop manually on paper first.
• Step 4 (15 min): While loop — write a while loop with a counter variable that starts at 0 and increments by 1 until it reaches 100. Print the final value.
• Debrief: "What is the difference between a for loop and a while loop? When would you use each?" Collect answers.
3. INDEPENDENT / PAIR WORK
Sequence Challenges
50 min
• Task 1 (20 min): Arithmetic Sequence Challenge — print the sequence 3, 6, 9, 12... up to 60 using a for loop. Then the sequence 100, 95, 90, 85... down to 0 using a for loop.
• Task 2 (15 min): Blink challenge — modify the Blink sketch so the LED blinks faster with each loop iteration. Use a variable for the delay that decreases by 50ms each loop.
• Task 3 (Extension, 15 min): Write a user-defined function void countDown() that counts from 10 to 1 and prints to Serial Monitor. Call it from loop(). Add a delay so it counts once per second.
• Sequence Parallel worksheet: complete the right column (for loop code) to match the left column (numbered English instructions).
• Navigator checks: is the loop output in Serial Monitor exactly what the English instructions described?
4. SHOWCASE & DEBRIEF
30 min
• 2 pairs show their times table output in Serial Monitor. Class verifies: "Is that the correct 7× table?"
• Facilitator asks one learner to verbally explain: "This is like the 7 times table because each time the loop runs, it adds 7." (Target phrase from ILO)
• Math connection close: write on board — for(int i=3; i<=60; i+=3). "What is the 5th term?" Work out together: 3+(5-1)×3 = 15.
• English connection close: display two parallel texts — English numbered list and the for loop. "Are these saying the same thing? Yes — just in different languages."
• Collect Sequence Parallel worksheets as this week's artifact.
