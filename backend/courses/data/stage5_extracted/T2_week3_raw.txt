Physical activity: stand in a circle. Facilitator says "outer loop starts — stand up and sit down 3 times while I count the inner loop." Learners sit and stand 3 times as the outer loop runs once. Total stands: 3 × 3 = 9 (for 3 outer iterations). Ask: "If the outer loop runs 5 times and the inner loop runs 4 times, how many total actions happen?" (20.) Connect: "That is a nested loop. Today you write them in code."
Distribute the blank multiplication grid. Learners have 3 minutes to hand-fill the 10×10 times table. They already know it — the task is to recognise it as a 2D pattern they can generate with code. "Every cell in this grid is i × j. Two nested loops will fill this entire table."
Trace table introduction (5 min): distribute the nested loop trace table. Facilitator demonstrates how to fill in one row: outer i=1, inner j=1, action = print 1×1=1, iteration count = 1. Pairs continue for the next 5 iterations independently.
Bridge: "The trace table is how professional software engineers debug nested loops. Before you write the code, trace it on paper. Before you upload, you should already know exactly what the output will be."
Multiplication table sketch (15 min): facilitator live-codes the nested for loop. for(int i=1; i<=10; i++) { for(int j=1; j<=10; j++) { Serial.print(i*j); Serial.print("\t"); } Serial.println(); }. Upload. Observe: does the Serial Monitor output match the hand-filled grid? Ask: "What does \t do? What does the outer Serial.println() do?" Pairs annotate both loop declarations with a plain-English comment.
Computational cost discussion (5 min): "How many times does the inner print line execute?" (100.) "If the outer loop ran 100 times and the inner loop ran 100 times, how many executions?" (10,000.) "This is called a quadratic cost — O(n²). It grows very fast. A good programmer always asks: can I do this with fewer loops?"
Triangular numbers (15 min): distribute the triangular numbers worksheet. Learners hand-calculate T(1) through T(6) using the formula T(n) = n(n+1)/2. Then write a sketch that generates the same sequence using a nested loop with a running sum variable. Print each triangular number to Serial Monitor. Verify: does the output match the worksheet?
Asterisk pattern challenge (10 min): distribute the pattern challenge cards. Challenge 1 — right-angled triangle: row 1 has 1 asterisk, row 2 has 2, row 3 has 3, up to row 5. The outer loop controls the row; the inner loop prints the asterisks. Upload and verify.
Rotate Driver/Navigator. New driver leads Challenge 2: rectangle of asterisks n × m where n and m are variables declared at the top of the sketch.
Function encapsulation task: write void printGrid(int rows, int cols) that uses a nested loop to print an asterisk grid of any dimensions. Call it three times with different row and column values. Calculate and print the total number of asterisks for each call using rows × cols.
Triangular pattern extension: modify the asterisk triangle so it prints an inverted triangle (row 1 has 5, row 2 has 4, down to row 5 with 1). Which variable changes — the inner loop start or the inner loop condition? Predict before coding.
Square numbers challenge: write a sketch that prints the first 10 square numbers (1, 4, 9, 16, 25, 36, 49, 64, 81, 100) using a for loop with the formula i*i. Then verify with a nested loop that generates n×n grids and counts asterisks. Do both methods give the same result?
LED blink pattern using nested loops: outer loop controls the number of blink groups; inner loop controls blinks per group. blinkGroup(3, 5) means 3 groups of 5 fast blinks each, with a 1-second pause between groups. Write this using nested loops.
Facilitator circulates. Ask: "How many total blinks does your programme produce? Calculate it before uploading." Observe participation, note on participation log.
Extension: write a function void printPascalRow(int row) that prints the nth row of Pascal's triangle using the combination formula. Print the first 6 rows. Identify where triangular numbers appear in Pascal's triangle.

CROSS-CURRICULAR LINKS
English | Sequenced technical explanation: learners must explain nested loop execution aloud to their partner step by step before uploading any sketch. "The outer loop starts at i = 1. While i is less than or equal to 10, the inner loop runs. The inner loop starts at j = 1. While j is less than or equal to 10, it prints i × j and moves to the next j. When j reaches 11, the inner loop ends. Then i increases by 1 and the inner loop starts again from j = 1." This oral explanation precedes every coding task. Translating procedural logic into clear, ordered English is treated as an explicit literacy objective.
Maths | Nested loops as multiplication: for(int i=1; i<=10; i++) { for(int j=1; j<=10; j++) { Serial.print(i*j); } } — this is the full multiplication table. Total iterations: 10 × 10 = 100. Triangular numbers: T(n) = 1 + 2 + 3 + ... + n = n(n+1)/2. The nested loop that generates them uses a running sum. Square numbers: for a square pattern of asterisks n×n, total characters printed = n². Computational cost analysis: if n = 100 and m = 100, the inner loop body runs 10,000 times — compared to a single loop that runs 100 times. This introduces the concept of O(n²) complexity, framed accessibly as "why some programmes feel slower."
