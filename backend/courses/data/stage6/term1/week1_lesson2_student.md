# Week 1 - Lesson 2

## Session length
**About half of this week's plan** (finish what you started in Lesson 1)

## Finish the week
- Set up the Arduino IDE: install drivers, select board (Uno) and correct COM port
- Upload the example Blink sketch and observe the LED blinking on pin 13
- Identify and name the purpose of: setup(), loop(), pinMode(), digitalWrite(), delay()
- Modify delay() values and predict and explain the effect on the LED
- Add a plain-English comment to every line of the Blink sketch using // syntax

## Continue

### 2. GUIDED ACTIVITY Blink & Read
1. Step 5 (10 min): Math link - complete the LED Timeline Worksheet. Mark LED ON and OFF over 5 seconds with the original and modified delay values.
### 3. INDEPENDENT / PAIR WORK Annotate & Modify
2. Task 1: Each pair modifies the Blink sketch to blink in a pattern: ON 2s, OFF 0.5s, ON 0.5s, OFF 2s. Write the code first, then upload.
3. Task 2: Add a comment to EVERY line of their modified sketch. Comments in full sentences.
4. Task 3 (Math): On the LED Timeline Worksheet, convert all delay values: express in both milliseconds AND seconds.
5. Task 4 (Extension): Add a second LED on pin 12. Make the two LEDs alternate - one ON while the other is OFF.
6. Navigator role: reads the code aloud while Driver types. Rotate midway.
7. Prompt for yourself when you are stuck: "What does this line do? Read it to me in plain English."
### 4. SHOWCASE & DEBRIEF
8. 2 you demo their blinking pattern to yourself. Explain: "What pattern did you make? What delay values did you use?"
9. Ask yourself 3 random you: "What is setup() for? What is loop() for? What does delay(1000) do?"
10. Peer feedback: audience gives one specific observation: "I noticed their LED blinked every [X] seconds."
11. Remember: write on board - Today's English link: Code comments are full sentences. Today's Math link: 1000ms = 1s.
12. Exit question (show of hands): "Who can tell me the difference between setup() and loop()?" Answer for yourself.
