# Week 3 - Lesson 1

## Session length
**About half of this week's plan** (you will finish in Lesson 2)

## Today you will learn
- ILO 3.2 — Apply variables, for loops, while loops, and user-defined functions to solve a mathematical problem computationally, demonstrating the connection between code structure and arithmetic sequence.

## Links to English and Maths
- **Maths:** Parallel structure activity: write a numbered list of instructions in English that mirrors the for loop exactly. Each numbered step = one loop iteration. "1. Print 7. 2. Print 14. 3. Print 21…" — then write the loop that does the same. You explain their loop structure to their partner verbally: "This is like the 7 times table because each time the loop runs, it adds 7." Times tables via for loops. Arithmetic sequences: first term, common difference, nth term. for(int i=3; i<=60; i+=3) — what is the first term? (3) Common difference? (3) Number of terms? (20). Sum of first 5 terms? Connect loop iteration count to multiplication.

## Let's begin

### 1. HOOK
1. The Human Loop
2. Physical activity: you calls out "Print 2!" — learner says "2". "Print 4!" — "4"... up to 20. "That was YOU being a loop!"
3. Ask: "How would you write that as instructions on paper?" Collect answers. Show how a for loop condenses this.
4. Write on board: for(int i=2; i<=20; i+=2) — translate each part: i=2 is start, i<=20 is stop, i+=2 is step.
5. Quick Math: given for(int i=3; i<=60; i+=3) — first term? (3). Common difference? (3). How many terms? (20). Class works this out together.
6. Get ready to use Sequence Parallel worksheet. Explain the task: complete both columns so the English instructions exactly match the loop.
### 2. GUIDED ACTIVITY
7. Times Tables in Code
8. Step 1 (15 min): You live-codes a for loop that counts 1 to 10, printing to Serial Monitor. You type along.
9. Step 2 (20 min): Pair task — write a for loop that generates and prints the 7× times table. Expected output: 7, 14, 21… up to 70. One learner writes pseudocode first, other types the code.
10. Step 3 (10 min): Verify, upload, open Serial Monitor. Check output. If incorrect — trace through the loop manually on paper first.
11. Step 4 (15 min): While loop — write a while loop with a counter variable that starts at 0 and increments by 1 until it reaches 100. Print the final value.
