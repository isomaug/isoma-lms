# Week 1 - Lesson 1

## Session length
**About half of this week's plan** (you will finish in Lesson 2)

## Today you will learn
- Set up the Arduino IDE: install drivers, select board (Uno) and correct COM port
- Upload the example Blink sketch and observe the LED blinking on pin 13
- Identify and name the purpose of: setup(), loop(), pinMode(), digitalWrite(), delay()
- Modify delay() values and predict and explain the effect on the LED
- Add a plain-English comment to every line of the Blink sketch using // syntax

## Big idea
ILO 3.1 - Interpret and write text-based Arduino sketches in Python that correctly use setup(), loop(), variables, digital/analogue I/O, and Serial.println() to control hardware.

## Links to English and Maths
- **Maths:** Reading code as structured text: identify the purpose of each line. Write code comments in full English sentences - "// This line makes the LED turn on for 1 second." Explicit instruction: comments are the author's voice explaining their writing to the reader. delay(1000) = 1 second. delay(500) = 0.5 seconds. You convert: 2500ms = ? seconds; 750ms = ? seconds. Plot LED state (ON/OFF) over 5 seconds on a timeline. Introduction to units of time in computing.

## Let's begin

### 1. HOOK What is a Microcontroller?
1. Show a real Arduino Uno on the projected screen. Ask: "What is this? Where might you find one?"
2. Brief class discussion: phone, traffic lights, washing machines - computers inside machines.
3. Introduce today's big idea: "We will write instructions for this microcontroller, just like a recipe."
4. Get your hardware ready. You hold the Uno and name parts: USB port, pins, chip, LED on pin 13.
5. Connect Uno to laptop via USB. Observe: does anything happen? (LED may flash during connection.)
6. Open Arduino IDE. Look through the interface: editor, verify button, upload button, Serial Monitor.
### 2. GUIDED ACTIVITY Blink & Read
7. Step 1 (10 min): File -> Examples -> Basics -> Blink. Open on projector simultaneously.
8. Read the Blink code aloud together, line by line. Ask: "What does this line do? How do you know?"
9. Step 2 (10 min): Select board (Arduino Uno) and COM port. Upload sketch. Observe LED blinks.
10. Step 3 (20 min): Get ready to use "Blink Code Reading Sheet". You read each line and write their comment in the blank column. You circulates - comments must be full sentences.
11. Step 4 (10 min): Pair challenge - change delay(1000) to delay(250). Predict first: "What will happen?" Upload and test. Were they right?
