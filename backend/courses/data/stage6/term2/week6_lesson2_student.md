# Week 6 - Lesson 2

## Session length
**About half of this week's plan** (finish what you started in Lesson 1)

## Finish the week
- Collect 20 simultaneous readings from TMP36 (temperature) and LDR (light) over a 5-minute period, recorded in a structured dual-column data table
- Plot both datasets as separate annotated line graphs on the same sheet — same x-axis (reading number 1–20), separate y-axes scaled appropriately, both labelled with title, units, and gridlines
- Calculate for both datasets: mean, range, and percentage change from reading 1 to reading 20
- Identify and annotate on each graph: the peak value, the trough value, and any visible trend segment (rising, falling, stable)
- Write a Technical Analysis Report of minimum 200 words, structured in three sections: (1) Data Summary (what was collected and how), (2) Comparative Analysis (differences and similarities between the two datasets with numerical evidence), (3) Interpretation and AI Connection (what the data suggests about the environment, and how this data could serve as training input for a machine learning model)
- Evaluate own report against the DDD Part 8.3 Stage 5–6 5-point rubric and self-assign a score with a written justification

## Continue

### 3. INDEPENDENT / PAIR WORK
1. Calculate, Write & Self-Assess
2. Task 1 (10 min): Calculate all statistics — mean (both), range (both), percentage change reading 1->20 (both). Write results in the statistics columns of the Dual Data Table.
3. Task 2 (30 min): Write the Technical Analysis Report — all 3 sections, minimum 200 words total. You circulates: check that Section 2 contains numerical evidence in every sentence. Prompt: "You said 'the LDR values were higher' — by how much? Give the numbers." Section 3 must name a specific AI application that would benefit from this type of dual-sensor data (e.g. adaptive lighting control, smart greenhouse, environmental monitor).
4. Task 3 (10 min): Self-Assessment — read own report against the DDD rubric card. Assign a score (1–5). Write 2 sentences justifying the score: "I gave myself [X] because… To reach a [X+1], I would need to…"
5. Extension: calculate the Pearson correlation informally — count the number of readings where both values increased simultaneously (positive co-movement), divided by 20. Express as a percentage. Is there a positive correlation between temperature and light in this dataset?
6. Rotate Driver/Navigator between Tasks 2 and 3.
### 4. SHOWCASE & DEBRIEF
7. 2 you share their graphs under the projector. Class reads: "What was the peak LDR value? What caused that?" Pair identifies the reading and the physical action that caused it.
8. Report swap: you exchange reports for 3 minutes and read Section 3 of a partner's report. Does it name a specific AI application? Does it explain HOW the data would be used? Peer verbal feedback: one sentence.
9. Self-assessment debrief: you ask 3 you: "What score did you give yourself? What would you need to change to score higher?" Do not reveal you's score — let the discussion happen first.
10. You then reveals own scoring of the shared reports. Compare with self-assessments. Discuss: "Was your self-assessment accurate? Why is accurate self-assessment a professional skill?"
11. Connection to Term 2 Demo Day (Week 8): "Your Term 2 project will need a data analysis section — this report is the rehearsal for that. Every graph and statistic you include in your Demo Day presentation should look like this."
